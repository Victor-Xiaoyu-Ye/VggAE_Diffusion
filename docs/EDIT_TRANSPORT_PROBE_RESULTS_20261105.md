# Stage62 实测：decoder 校准有效，RAE 的补全优势尚未成立

审核日期：2026-11-05。结果来自用户下载的
`D:/中转站/VGGAE/scale/edit_transport_probe_v1` 及其 `_smoke` 目录。
这是冻结 codec 的编辑机制实验，不是 Stage61 续训，也没有训练或运行新的文本视频编辑器。

**主要结论：H1 支持用目标源状态的 decoder 响应校准 token 编辑，但不能据此证明
RAE 比 RGB/VAE 更适合编辑。H2 中，当前 RAE 在稀疏观测下优于当前 Wan VAE
逆写对照，却在全部 24 个源案例上落后于边缘感知 RGB 补全。不能把这轮写成
“RAE 编辑已经取得独有收益”，也没有依据继续扩大原辅助 loss 的训练规模。**

## 2. 实际执行的任务

每个 Stage60 dev 源视频只取第一帧，保持比例 letterbox 到 518，构造九个已知
二维仿射状态；末状态旋转 4°、平移 (22,12) 像素、放大 1.08 倍。测试状态 4/8，
编辑强度 0.5/1.0。编辑是预定义软椭圆内的 RGB 增量 `[.02,-.03,.10]`，不是文本
指令、语义物体 mask、自然运动、3D 相机运动或遮挡生成。

RAE 使用实际 StreamVGGT/生产 C256 AE；encoder 看九个合成源状态，decoder
单帧 FP32。Wan VAE 是 T=1 图像模式，518 居中 pad 到 528 后裁回。
优化只改变每个目标状态的 latent 增量，不更新模型参数；Adam 40 步，lr=.03，
归一化增量 ridge=1e-4，逐元素 trust=1.5。结果取观测目标函数最优的迭代状态。

H1 的目标是“anchor latent 编辑实际解码出的 RGB 变化，再做已知二维传输”。
它刻意采用 decoder 定义的目标，检查直接搬运 token 是否保持同一个可见编辑效果。
校准器可见全部目标效果，RGB oracle 可以精确传输，因此它不是未知目标预测测试。

H2 改用 codec 无关的解析 RGB 变化。覆盖率 1.0/.25，观测噪声 0/.005；.25 是
8×8 粗块的采样概率，另有各方法共享的小编辑 seed，并非每个案例恰好 25% 像素。
隐藏目标值只用于评估。RAE/VAE 从零增量出发，各目标状态独立求解；当前没有
跨状态共享的编辑变量或多帧联合约束。RGB 对照使用相同观测，执行 120 次源图
边缘感知 harmonic 补全，并有粗初始化及软观测约束。

展示的是 `source RGB + decoder 的编辑差分`，不是直接用低 PSNR 的 RAE 重建
替换整个源视频。源预览 MP4 第三列是解析编辑目标，不能称为模型生成结果。

## 3. H1：校准确实修正了直接 token 传输

强度 1.0，两个目标状态平均。误差越低越好；effect gain 理想值为 1，不编辑为 0。

| 方法 | 全有效区 effect L1 | 编辑区 L1 | effect gain |
|---|---:|---:|---:|
| 不编辑 | 0.016698 | 0.027888 | 0 |
| 直接 token warp | 0.010956 | 0.016052 | 0.6960 |
| token 效果的最优标量拟合（oracle） | 0.010264 | 0.015384 | 0.6563 |
| warped-anchor 近似响应控制 | 0.008512 | 0.013029 | 0.8161 |
| **目标状态 decoder 校准** | **0.003852** | **0.005764** | **0.9467** |
| RGB 精确传输 oracle | 0 | 0 | 1 |

- 校准相对直接 token warp 的编辑区误差降低 **64.09%**，24/24 案例、48/48 状态改善。
  相对最优标量拟合降低 62.53%；相对近似响应控制降低 55.76%，也均为 24/24 案例改善。
- gain 从 .6960 到 .9467，说明改善不能解释为单纯缩小编辑幅度。强度 .5 时，
  编辑区 L1 从 .008782 到 .004323，降低 50.78%，同样 24/24 案例改善。
- 编辑区 L1 的源案例配对差值为 -.010288；20,000 次 clip bootstrap 的描述性
  95% 区间为 [-.013109,-.007913]，没有跨数据集或多随机种子的显著性结论。
- **没有统一的背景保持收益。** 强度 1 时 keep leakage 为 .003877→.003882，
  基本不变；强度 .5 时还上升。H1 的 ROI 由目标效果 >2/255 定义，目标本身在
  ROI 外仍可有小变化，连 RGB oracle 的该项也不为零；不能误解为理想背景必为零。

逐图看过 24 个状态 8/强度 1.0 的 H1 对照。森林/帐篷、海滩、竖幅农田、纸面
等案例的校准效果更接近目标；直接 token 和标量拟合往往保留较大偏差。
但目标是局部色偏探针，不能把森林例子解释成成功执行了原 Senorita 的帐篷编辑指令。

**支持的 insight：重建可行并不意味着编辑增量可以跨上下文直接搬运；decoder
能把“应当保持的可见编辑效果”转成可优化约束。边界：完整目标已知、增加了优化
预算，RGB oracle 为零误差，因此不是 RAE 独有性或编辑系统优越性的证据。**

## 4. H2：RAE 胜过当前 VAE 对照，但 RGB 补全更好

主设置为强度 1.0、观测采样 .25、噪声 .005。隐藏编辑区误差衡量未观测编辑
是否被补出来；背景 leakage 衡量编辑外的额外变化，二者均越低越好。

| 方法 | 隐藏编辑区 L1 | 全编辑区 L1 | 背景 leakage | effect gain |
|---|---:|---:|---:|---:|
| 不编辑 | 0.046585 | 0.046679 | 0 | 0 |
| 仅稀疏 RGB | 0.046585 | 0.034544 | 0.001108 | 0.2852 |
| **边缘感知 RGB 补全** | **0.023051** | **0.017914** | **0.004689** | **0.6407** |
| RAE 逆写 | 0.036810 | 0.029209 | 0.011026 | 0.5273 |
| Wan VAE 逆写 | 0.058958 | 0.044619 | 0.022405 | 0.4967 |

RAE 的隐藏编辑区误差比 VAE 低 **37.57%**，24/24 案例改善；但比 RGB 高
**59.69%**，24/24 案例都更差。RAE 的背景 leakage 比 VAE 低 50.79%，却比
RGB 高 135.16%。RGB 的编辑 gain 也更接近 1，不能解释成靠“少改”获得好指标。

不是只挑一个噪声或强度后才出现的结果：

| 强度 | 噪声 | RGB 隐藏编辑区 L1 | RAE | VAE |
|---|---:|---:|---:|---:|
| .5 | 0 | .011602 | .020026 | .037243 |
| .5 | .005 | .011617 | .020048 | .037434 |
| 1.0 | 0 | .023049 | .036793 | .058954 |
| 1.0 | .005 | .023051 | .036810 | .058958 |

全观测时排序反转：强度 1、噪声 0 的编辑区 L1 为 RAE .010459、VAE .008176；
另外三个全观测设置也均为 VAE 更低。不能概括成“RAE 比 VAE 更可编辑”。

已查看 24 个 RAE H2 对照和本地有图的 15 个 VAE 对照。RAE 经常只改到部分观测
色块，没有完整恢复目标椭圆；VAE 还出现明显的局部碎纹理/形状破坏，例如森林、
花束、杯中水果、蝴蝶与花、鸡蛋背景。RAE 的较低误差有画面支持，但也确实未完成
完整编辑。后九例缺失的 VAE PNG 用灰色缺失标记，不替造图像。
RGB 补全只有全量数值、此轮没有保存对应 PNG，因此不冒充已完成其逐图视觉比较。

## 5. 为什么不能把对照差异过度解释成表示优劣

**迭代预算还不是收敛结论。** 全量解析了 960 个求解日志。强度 1、无噪声、
稀疏观测下，RAE 的观测相对 MSE 从 1 到 .06672，VAE 到 .03524；各 48 个状态
的最佳已记录目标函数仍在第 40 步。VAE 更好地拟合可见观测，隐藏误差却更高，
与欠约束下的过拟合一致，但尚不足以锁定成因。第 20→40 步两者仍明显下降。
相同 40 步/lr 不是各 codec 分别调优后的极限，也不是相同墙钟预算。

**近似响应控制有优化稳定性混杂。** H1 强度 1 的 calibrated 观测相对 MSE
从 .3962 降到 .06772；近似响应控制最后一步却到 11.7388。最终评估使用的是
每一步中观测目标函数最优的增量，不是这个发散的末步。这里的 `fixed_response`
固定的是 warped-anchor 基态，反向响应仍随增量变化，并非一个固定线性 Jacobian。
这说明当前近似梯度/lr 组合不稳，不能外推为所有近似响应校准都不行。

**codec 本身没有完全匹配。** 48 个独立目标状态的重建 PSNR：RAE 平均 24.134 dB、
VAE 38.247 dB；每状态可编辑 latent 元素分别为 82944 和 69696。RAE 编码看九帧、
VAE 看一帧。生产 C256 还含 RGB 分支，不能把 RAE/VAE 的差值唯一归因于 VGGT 几何。
没有 DINO-RAE 对照。

**H2 的信息条件很有限。** 独立目标状态的遮块 RGB 拟合，尚未提供跨帧共享编辑
变量、真实对应/可见性、物体支持或可靠编辑参考。平滑局部颜色变化本身也适合 RGB
插值。此结果应保留为负面基线；不能只靠换一个有利任务就宣布已经解决该问题。

## 6. 对项目和下一步的影响

Stage61 的“加 AE 特征监督即可改善视频编辑”没有稳定正收益；Stage62 为不同的
“把 decoder 用于编辑状态读写”路线提供了第一项有边界的正证据。二者不要混为一谈。

目前可写入论文动机的事实是：**直接 token 编辑传输会改变其可见效果；通过目标
状态的解码响应可以校正。** 尚不能写成实证结论的是：“这比 RGB/VAE 的方法更好”、
“几何理解带来收益”、“可以稳定编辑真实动态视频”或“原生生成器输出已获改善”。
不需要为此重训基模；缺的是小规模但有判别力的机制与输出验证。

建议后续实验按以下顺序准备；本次只审阅，未新建或启动这些实验：

1. 在现有小样本上补求解预算/稳定性曲线，分别报告观测与隐藏误差；对各 codec
   给同等调参预算，另做相同墙钟预算比较。近似响应控制先验证学习率/线搜索稳定性，
   区分“状态响应差异”与“所选优化器不适配”。这些是分钟级机制计算，不是新一轮长训练。
2. 明确自然任务输入：一个合法编辑 anchor 加源视频对应与可见性，在多个源状态
   上联合维护同一编辑。所有 RGB/VAE/RAE 方法共享 anchor、对应、mask 与优化信息；
   继续保留当前 RGB 补全及不编辑对照。目标是验证真实对应不完整时的输出收益，
   不能只报告 latent 拟合 loss。
3. 只有小规模自然片段出现可靠额外收益后，再接 native VACE 实际写回，比较
   相同前端/seed 的任务效果、保持性与成本。否则更换编辑先验/约束或问题定义，
   不继续把“RAE 可解码”本身当作有效补全先验，更不以扩大数据量掩盖这项负结果。

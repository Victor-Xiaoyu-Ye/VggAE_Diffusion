# 重建与生成差距的调研及实验选择

2026-10-23。对应当前 Stage53/54 的固定窗口街景任务：观察4帧、联合生成5帧，冻结 SceneRAE C256 和归一化统计。本文是调研和实验建议，不是新训练实现，也没有取得新的集群结果。

当前证据最支持优先调查 **未来外观状态的可建模性，以及预测误差经 decoder 转换成 RGB 的方式**。尚不能唯一归因于数据量、模型容量、StreamVGGT、缺少时间压缩或 decoder。继续扩大同一目标的回归预算，缺乏足够明确的收益依据。

## 本项目已经知道什么

当前状态是 geo128 与 texture128 拼接。geo 来自冻结 StreamVGGT 的多层特征，经可训练压缩；texture 来自可训练的逐帧 RGB CNN。整个 C256 并非纯冻结基础模型特征，也不是静态/动态分解。texture 能存位置、轮廓和形状，名字不代表它仅存颜色。

每帧518×518×3压到18×18×256，元素数约压缩9.7倍；没有时间压缩。当前 RGB decoder 逐帧工作，geometry encoder 有因果历史。DiT 则联合预测整个未来窗口，不是逐帧自回归。逐帧重建能够播放出运动，是因为每个真实未来帧的状态都已经提供；这不检验未来预测能力。

当前 DiT 有831,305,344参数，主干768×24、宽头1536×6，已经使用 x0 参数化、维度相关训练 time shift4.5、多帧历史与 FP32 EMA。AE 后期交替使用干净 latent 和按通道标准差缩放、最高0.05的 Gaussian jitter。它的 feature restoration 与 relation loss 仍看干净的完整 C256。不能再把宽头、x0、shift、多层特征或普通白噪声增强当成尚未采用的新答案。

Stage54 的相同64case×2seed比较中，motion EMA 的 RAW L1 比 control EMA 差0.409%，人物重影未改善，尽管高变化区域去噪指标和帧差幅度有所改善。近期增加变化区域回归权重，未跨过动态轮廓的质量瓶颈。[结果与证据](SCENE_MOTION_RESULTS_20261022.md)

七个预选case的未来GT分支替换有更强定位价值：

| control EMA 的七例 RAW L1 | 值 |
|---|---:|
| AE重建 | .072219 |
| 正常生成 | .122837 |
| GT geo + predicted texture | .122626 |
| predicted geo + GT texture | .072095 |

这说明恢复未来texture能恢复大部分可见质量差距，但并不证明geo无用或decoder是唯一原因。geo可能预测较准，也可能局部敏感度小、信息冗余或受到混合latent分布变化影响。这些是使用未来真值的诊断，不能当生成结果，也不能与64例全量均值混用。

旧C192已经做过decoder扰动诊断：相同每slot规范化RMS，生成误差方向的RGB L1约.0995，随机方向约.0527；小幅扰动响应平滑。旧memory64轨迹也出现过中途预测优于最终采样的情况。它们提示误差方向和轨迹重要，但不能直接当作当前C256的机制结论，更不支持原样重跑旧实验。[历史实现说明](WINDOW_DECODER_DIAGNOSTICS_RUNBOOK.md)

## 为什么重建成立而生成仍然失败

重建检验的是 D(E(x))；生成需要 G(noise, observed history) 落入一个能被 D 合理解释的联合时空状态。前者不约束这个状态分布是否容易学习，不保证状态附近所有方向都能稳定解码，也不衡量不同真实未来之间的多模态不确定性。

三个问题要分开：

1. **保留了什么信息。** 干净latent能重建人物，说明它保存了相应信息。
2. **信息如何组织。** 同样的轮廓可以编码成稳定、容易预测的结构，也可以藏在相互抵消、低能量或高度相关的细节坐标中。重建分数难以区分两者。
3. **预测偏差如何变成像素。** 局部近似 D(z+e)-D(z)≈J_D(z)e。相同latent MSE，不同误差方向可以产生很不同的轮廓损伤。此式说明需要测方向敏感性，不是已经测出本项目的Jacobian。

当前生成训练只优化规范化latent回归，没有通过冻结decoder回传RGB/感知损失。加权MSE改善不等于人物边界改善。但不能反过来说“MSE天然只能生成平均人”：正确学习的扩散/flow可以用平方损失生成多模态样本。中间一步的条件均值与完整采样的分布不是同一件事。

自由采样结果与唯一真实未来之间的差也包含合理的运动分歧。因此，不能将所有 sampled-minus-GT 都当作错误噪声，更不能直接训练decoder把任意自由采样结果压回唯一GT未来。

## 最有针对性的文献

下列数字是论文各自设置下的报告，不能跨论文或与本项目直接比大小。

| 工作 | 核实到的方法或证据 | 对我们的启示与边界 |
|---|---|---|
| [MIRA，Table3/5](https://arxiv.org/pdf/2607.05352) | 冻结DINO编码器PSNR29.7、gFVD163.1；从头训练编码器PSNR32.2、gFVD375.0。无时间下采样的生成表现与有下采样接近。 | 重建更高不代表状态更容易生成。值得怀疑RGB texture分支的组织方式，但这不是对本分支的因果证明，也不支持把无时压缩当唯一错误。 |
| [LV-RAE，2602.08620，§3.3/Table4](https://arxiv.org/html/2602.08620v1) | 补充低层信息后分析decoder对离数据分布方向的敏感性；以随机强度噪声微调提高容错，固定大噪声会伤害干净重建。 | 与“重建好、预测小偏差造成伪影”直接相关。我们已有jitter；应匹配实际误差方向/强度，不照抄噪声数值。论文方案还包含对抗项，不能将全部效果归于加噪声。 |
| [RoAR-VAE，2610.26216，10月19日，§3](https://arxiv.org/html/2610.26216v1) | 从带噪latent预测干净语义与RGB；梯度更新encoder，另保留干净重建路径。RGB辅助decoder独立，训练后丢弃。 | 真正区别在于塑造表示的可恢复性，不只是让最终decoder忍受噪声。我们目前feature/relation只监督干净z。该文是图像VAE结果，应用到冻结VGGT后的可训练瓶颈仍需验证。 |
| [V-RAE，2608.13556，§4.3](https://arxiv.org/html/2608.13556v1) | 用相邻时刻latent中点替换内部状态，再解码检测时域几何；好重建仍可在插值状态上出现重影。 | 借鉴离开精确编码点的压力测试。latent中点不是真实中间动作，不能要求所有运动严格线性；其视频encoder设定也不等于StreamVGGT。 |
| [GAE，2609.24981v4，10月14日修订，§3](https://arxiv.org/html/2609.24981v4) | DA3多层特征经64/128通道状态，同时支持RGB与冻结几何头；另以token语义和关系约束组织表示。压缩保持时间维。 | 成功并非直接对原始几何特征加噪即可。我们的RGB来源texture和full-z恢复头与其约束不同；现有关系损失不等于已实现同样的信息组织。 |
| [CADRE，2610.30129，10月21日，§4.1/附录C](https://arxiv.org/html/2610.30129v1) | 冻结特征、小瓶颈、因果diffusion decoder；其重训MIRA配方PSNR更高但FVD更差。codec训练混合约76k小时。 | 紧凑状态预测与细节渲染可以分工，是有依据的升级路线。数据/训练成本很大；当前AE已能恢复部分动态细节，不能直接认定必须换随机decoder。 |
| [Diffusing in the Right Space，2606.03578](https://arxiv.org/html/2606.03578v1) | 对多种tokenizer/backbone比较可生成性，分析语义、空间组织与速度歧义等指标。 | 支持用下游生成而非单一重建指标选表示。统计相关性和类条件高斯分析不是我们视频空间的定理；不应据此强制全白化。 |

另外几个已有方向需要准确定位：

- [RAE](https://arxiv.org/html/2510.11690v1) 的宽度、shift、宽头与噪声增强启发已经部分落实；当前width768大于token256，不能用输入宽度不足直接解释全部失败。
- [On the Diffusibility of High-Dimensional Latents](https://arxiv.org/html/2609.28473v1) 支持强重建表示上的x0参数化；当前已经使用x0，不是漏了这个开关。
- [FreqWarm](https://arxiv.org/html/2511.22249v1) 是先低通RGB再编码的训练课程，不是直接平滑latent；已展示的生成实验是图像，不能由人物模糊推出必须删除latent高频。
- [RAEv2](https://arxiv.org/html/2605.18324v1) 的DiT中间特征对齐与AE自身对齐不同。当前多层VGGT融合不等于生成器已接受中间层监督；历史aux6/8也不能作为当前表示上任意REPA方案的充分否定。
- [SemanticGen](https://arxiv.org/html/2512.20619v3) 将语义状态规划与预训练视频模型渲染分开，提供替代路线依据；采用它会改变生成先验和项目比较口径，不应称为原方案的简单优化。

## 根因判断的优先级

**优先级一：外观状态的学习难度与视觉敏感方向。** 本项目分支替换定位与MIRA编码器消融相容。texture既可以帮助重建，也可能让DiT承担没有充分预训练组织的细节分布。当前证据不足以判断其主因是条件歧义、目标分布、模型优化还是decoder响应。

**优先级二：生成训练目标缺乏可见结构反馈。** motion加权没有修复人形，是本项目已做过的反例。应检查去噪器在不同噪声、未来位置和分支上是否学会了轮廓，而不是只看一个全局平均数。

**优先级三：表示与解码中的时域组织。** 逐帧decoder缺少修复跨帧不一致的机制，但本身并不证明架构无效。时间压缩更不是必需条件。为省token盲目增加时压缩，可能损伤小物体与快速运动。

**尚未证明的解释：** 数据不够、参数不够、VGGT不适合动态视频、必须改成WASD、必须换采样器。当前街景任务已经收窄，历史稳定性问题也有修复；这些因素可以影响上限，但不能替代现有分支证据。相机条件减少相机运动歧义，不能自动指定行人动作或修复外观表示。

## 下一轮应如何改变判断

目标仍是固定窗口可见质量，不增加长视频任务，不新增大批人工标注。只保留一轮有决策作用的诊断，并选择一个干预，不把所有技巧一起装进去。

| 顺序 | 具体做法 | 能区分什么 |
|---|---|---|
| A 当前checkpoint定位 | 保存高/中/低噪声的x0与自由采样轨迹；按geo/texture、未来帧、局部轮廓拆分。对低噪声GT-corrupted配对预测误差及等RMS随机/分频扰动做对称解码。复用已有oracle。 | 从高噪声就缺结构，还是后段损坏结构；外观误差大，还是同量误差被decoder放大。与旧C192诊断的区别是当前C256、分支和配对噪声条件，不重复旧矩阵。 |
| B1 若主要是decoder放大 | 冻结encoder、统计和DiT；用训练集干净状态及校准的小幅结构化扰动适配decoder。与原decoder解码完全相同的sampled latent。 | 不改生成状态即可改善，支持解码容错问题。须同时看干净AE、人物边界和运动，防止靠模糊换鲁棒性。 |
| B2 若decoder已稳定但去噪结构不足 | 固定AE和数据，对照原latent目标与低噪声解码感知辅助，或中间token关系监督；一次只选一项。 | 直接检验latent欧氏误差是否忽略了可见关键方向。低噪声辅助是项目假设，不是上述论文已验证的现成VGGT方案。 |
| C 若外观状态本身难学 | 冻结StreamVGGT骨干，训练瓶颈/外观分支时增加从带噪状态恢复干净语义、空间关系及RGB的辅助读出，并保留干净重建。再用匹配小DiT比较。 | 改变信息组织，而不只是继续回归旧状态。更新表示后必须新缓存、新统计，不能直接续旧DiT并称严格对照。 |
| D 若紧凑状态不支持可靠确定性渲染 | 评估VGGT结构状态 + 时域条件/随机外观decoder，参考CADRE或SemanticGen。 | 将未来结构和高频实现分工。属于较大路线变化，需单独验证几何忠实度和时序闪烁，不能仅看更锐。 |

当前最值得投资的实质方向是C中的“带噪状态仍可读出结构与细节”，B1是低成本验证能否保留现有成果；不是默认认定B1足够解决问题。A只负责选择干预，不新增阻止后续训练的质量门槛。

动态mask可用于局部评估及有置信度的辅助监督。它提供“哪里动”，不提供“未来何种形状与外观”。不能直接将动态token跨帧attention禁掉：运动对应关系本身需要跨帧信息。相机补偿与unknown区域仍需保留。Stage55继续是独立诊断，结果尚未证明mask质量或生成收益。

## 评价与执行约定

所有训练对照固定RGB集合、未来窗口、条件、初始化口径、更新数/曝光、噪声与采样预算；分别报告AE重建和真实自由生成。不要用已经带真值的去噪结果替代生成。

少量固定视频用于排错和视觉对照，不用64例FVD当稳定的论文级分布结论。扩大评价时排查物理视频父来源隔离，避免用长期反复看的开发集代替独立测试。L1作为配对诊断，人物身份/边界、连贯运动、遮挡和动态量一起判断，防止复制、静止或锐化伪影获胜。

仅凭本次survey不能承诺质量提升。下一实现保留双读双写、阶段ckpt、可恢复中间结果、失败样本记录、真实DI_throughput和idle guard；本次没有更改这些机制，也没有启动训练或下载新模型。

### 当前必须承认的缺口

- Stage58 确有有限增益：matched 64 cases × 2 seeds 的 oracle 相对 baseline，RGB L1 降低 6.23%、texture MSE 降低 16.45%，只闭合约 12.77% 的 baseline-to-AE RGB 误差差距。它需要真实未来特征，不能计作可部署画质突破，也不是充分训练后的能力上限。
- Stage57 的 GT texture 替换和结构误差实验指向外观预测/解码链路；不能由此直接断定 encoder 无效或 decoder 是唯一原因。当前 texture128 是学习的 RGB 编码，不是纯 VGGT 特征。
- 固定 train/dev 的自由采样、强语义表示正对照，早在本文件 10 月 13 日版本已要求，至今仍未完成；这是执行缺口，不是今天才发现的新研究方向。后续实验必须交付这些结果，不再以更多日志诊断替代。
- Stage56 的零 track/reference 支持使预期对照未运行。相机、depth、track、mask 的数值存在与有效信息存在必须分开；独立有效实验继续运行，缺失条件的实验不能算作该方法的失败或成功。
- 尚未隔离拟合、泛化、表示组织、解码敏感性；没有证据把主要原因归为参数少、数据少、VGGT 原理不可行或所有动态模糊都是条件均值。

| [V-RAE](https://arxiv.org/abs/2608.13556)、[VideoRAE](https://arxiv.org/abs/2607.14088) | 视频表示 AE、时间组织与视频解码不能单独作为新意；具体 encoder/任务/训练配方应分开复现。 |

| [VideoWeave](https://arxiv.org/html/2606.14162v1)、[Latent Bridge，10/20](https://arxiv.org/html/2610.28521v1) | 几何与视频 latent 联合扩散/蒸馏、从视频 latent 桥接几何特征已有工作；二者方向不同，不能混称一个方法。 |
| [GAD](https://fantasy-amap.github.io/GAD/)、[Go-with-the-Track](https://arxiv.org/abs/2606.20891) | 几何 attention 对应蒸馏、轨迹加参考条件已有强对照。 |
| [SyncVid，10/22](https://arxiv.org/html/2610.31765v1)、[CameraNoise](https://arxiv.org/abs/2605.30774) | 几何对应噪声、噪声运输与边缘分布校正已有先例。 |

### 方案空间与优先级

这里覆盖主要独立决策方向，不声称穷尽一切未来方法。低/中/高仅为相对工程与训练负担，不是成功概率。

| 路线 | 具体变化与用途 | 成本/主要风险 | 优先级 |
|---|---|---|---|
| 1. 匹配的视频 RAE 正对照 | DINO 前端与 StreamVGGT 聚合特征进入相同 bottleneck、视频 decoder、DiT 配方；另保留当前 hybrid | 中高；decoder/缓存均要训练，维度与重建上限不同须披露 | 先完成；基线能力，非创新 |
| 2. 时序/生成式解码 | 历史已有 temporal decoder 和 Gaussian 鲁棒适配；新架构须说明相对旧实验的增量，再固定 latent 对比 | 中；锐化可能掩盖错误运动或改变身份 | 降级为有明确增量的对照，不自动重跑 |
| 3. 几何对应下的可生成表示 | 可靠对应区域复用历史外观，模型生成运动相关变化和新可见内容；明确未知区域 | 高；latent 运输不一定等同 RGB 运输，teacher 当前不可用 | 首选论文候选，须先证机制 |
| 4. 结构误差适配的 codec/denoiser | 区分外观、位置、跨帧误差；匹配真实去噪误差而非仅随机 jitter | 中；LV-RAE/OneWorld 已覆盖通用版本，可能损坏 clean AE | 路线3的候选部件，不能单独包装 |
| 5. 几何/运动与外观层次生成 | 先采样几何/运动，再条件生成外观；训练覆盖预测条件误差 | 高；oracle 目前仅有限收益，误差串联 | 备选，不据 Stage58 直接扩规模 |
| 6. 原生视频先验加几何状态 | 保留 pretrained video codec/denoiser 的有效接口，几何负责可检验的对应、遮挡或控制 | 中高；质量先验更强，但新颖性拥挤 | 质量参照与失败后的主转向 |
| 7. 教师向 VGGT 生成器迁移 | 用成熟 video teacher 的输出或轨迹蒸馏到 VGGT 派生目标空间 | 高；跨 latent 噪声/时间并不对应，不能直接照抄 score | 高风险备选，先验证可迁移性 |
| 8. 分布/对抗后训练 | 在生成视频上约束真实外观和运动，防止逐像素指标偏好模糊 | 中高；训练不稳、身份/几何漂移、已有强先例 | 有合理视频基线后 |
| 9. 对应保持的扩散噪声/预条件 | 频率课程、可逆 whitening、协方差/几何相关噪声 | 低至中；噪声分布和采样公式必须一致，已有密集先例 | 有明确统计证据再做，不盲扫 |
| 10. 缩小任务为补全/插帧/重定向 | 增加末帧、关键帧或参考视频，保留固定窗口 | 中；任务更受约束，不能与 prefix-only 混表 | 截止期优先的明确转型 |
| 11. 系统性可生成性研究 | 跨 encoder、codec、域和预算研究重建/预测/解码误差关系 | 中高；只报告本仓库失败不够，已有大量相近研究 | 稳定规律出现后的独立论文路线 |
| 12. 离散 token/AR、3DGS/4D state | 彻底更换生成状态或建模家族 | 很高；已有 prior art，新增误差源多、旧资产复用少 | 近期不推荐 |
| 13. 纯数据/容量扩展 | 单域课程、增加独立运动窗口、增大 DiT/AE | 中至高；不能诊断当前失败，也通常不是独立贡献 | 可靠正对照后再决定 |

### 首选研究问题与两条有限路线

首选问题：**几何对应能否把动态视频中的外观组织成容易复用、容易生成的状态，同时为遮挡与新内容保留随机性？** 这仍是假设，不是已发现的创新。研究对象保持固定窗口，先不加入长视频、WASD UI 或多 agent。

路线 A 保留 VGGT 派生特征扩散，但放开自定义压缩/外观支路/decoder。先用匹配正对照恢复合理画质，再从一个具体机制选择方法：对应区域的外观运输与残差生成、未知区域的不确定性建模、或几何特有的结构误差适配。不能把这三者一次全部堆上。贡献必须超过普通时序 decoder、普通 past-conditioned decoder 和 2D-flow-only 运输。小物体、快速运动、相机与物体同时移动、遮挡重现是必要分层。

注意：简单做 `warp(reference) + residual` 已有历史工作，不是新算法。候选差异是**如何使 VGGT 派生表示本身支持可靠的运动对应与生成**，以及在估计有误/区域不可见时如何避免复制错误；若未测出这方面优势，就不能保留这一主张。几何 readout 应在独立数据/评价器上检查，不能仅用训练 teacher 自评。

路线 B 保留成熟视频模型的 native appearance prior，VGGT 负责可验证的几何作用。它是质量风险对冲，不能只改成“Wan + VGGT”后称论文。将目标限制为可验证的短窗控制/补全，比较相同相机不同物体运动、相同物体运动不同相机、遮挡后重现等；需要真正可用的控制数据。加载 Wan 权重到新的 C256 空间不等于保留这种 prior。若最后沿用 native VAE，应明确放弃纯 VGGT-latent generation 主张。

### 下一轮必须交付的有限实验包

1. **补齐既有承诺，而非重复诊断。** source/baseline 的固定训练样本与 source-disjoint dev 均从纯噪声自由生成；保存训练 ID、历史/目标边界、时间间隔、seed 和只评 future 的媒体。训练样本拟合失败与泛化失败分别处理，不靠监督 loss 判定。
2. **先复用历史 decoder 结论，再决定是否做增量对照。** 已完成的 Gaussian `decoder_robust`、历史 temporal decoder、Stage34/57 扰动诊断不能重新当成空白方向。尚未找到当前 C256 固定生成 latent、只增加时间模块并用配对结构误差适配的已完成训练记录，但这个精确组合未跑不构成自动立项理由。只有相对已有 jitter/temporal 方法有明确假设时，才在相同 clean/生成 latent 上做隔离对照；训练仅用 train 数据，使用同一 GT 加噪后的配对去噪预测，不把任意自由未来强配给唯一 GT。保留 clean AE、运动幅度、身份与几何，避免仅奖励锐化。匹配视频 RAE 正对照优先于再次泛化地微调 decoder。
3. **真正的表示正对照。** 当前 hybrid 作为历史系统；DINO 与 StreamVGGT 使用同一视频 codec/生成配方，先不加入额外 motion loss。若需新投影，它属于各自 codec 并计入成本。公开实际 token 数、decoder 容量、可训练参数、数据曝光与 NPU 小时；既看相同预算，也看接近重建质量下的结果。使用 DINOv2 前端便于已有权重复用，但不能称已复现 DINOv3/EUPE 的论文结果。
4. **原生视频质量参照复用现成资产。** 相同 RGB 片段、分辨率/FPS/时长报告清楚；若 native 模型只接受单图而我们接受四帧，应标作系统参考，不冒充输入匹配消融。

不要一次训练完整的 13 条路线。现有 831M 配方每臂 2000 步约 3.1 小时（含 IO/eval）只为同配置参考；新 codec、temporal/diffusion decoder、teacher 反传时间未知。先实测吞吐/显存再排总预算，不许套用旧速度承诺几天必出好结果。保存中间结果，单臂失败不取消独立有效实验。

结果决定下一步：

- DINO 与 VGGT 都差：先查共同视频生成实现/数据/预算，不归罪 VGGT。
- DINO 成功、VGGT 失败：研究特征组织、压缩与解码；先控制重建上限，不能只比较最终 FVD。
- 新 codec 的 VGGT 明显优于当前 hybrid：淘汰旧表示作为主线，不继续保护既有 ckpt。
- train 好、dev 差：优先有效独立数据覆盖/域差异；train 也差：优先拟合和采样链路，不直接买更大模型。
- decoder 只让纹理更锐但运动仍错误：限定其收益为解码，转向运动/对应建模。
- 几何方法不优于 DINO/past-conditioned/2D-flow：撤回几何必要性主张；可转 B 或更一般的 codec 研究。
- 多个关键机制失败：选择受约束任务或停止该假设，不无限追加 schedule/mask/aux 权重试验。

### 投稿证据与数据（与运行安全检查分开）

最低论文证据包括：合理的未见场景视频；一个可区分且有机制证据的方法；同条件/预算强对照；独立几何或运动评价；两类数据的外部验证；干净重建与动态质量不互相抵消；公开失败与计算成本。不能以“生成成功”自动等价于顶会贡献，不能承诺录用。

既有 64 例已多次用于开发，后续论文需要新冻结的 source-disjoint test；不反复在这 64 例上挑选方法再作为无偏最终测试。检查曝光必须覆盖 AE、warm-start DiT 与新训练全部阶段：不能从已参与 AE 的 8192 个街景来源重新切几例，就称从未见过的测试。像素 L1/PSNR 只作配对诊断，随机未来必须同时评价感知质量、运动、身份、一致性与多样性；不能靠静止视频赢平滑/稳定指标，也不能用少量短片 FVD 排名冒充充分证据。

数据优先使用已核验的 SpatialVID 街景真实连续视频，分相机运动、独立物体运动和二者同时发生；保留动态对象，不筛成静止背景。DL3DV 等静态场景用于几何/codec 辅助和对照，不能无区别当动态时间序列。PointOdyssey/Spring 可作为独立运动几何验证来源，但先确认现有 WAI 版的 RGB 连续性、官方 split、相机/flow/track/visibility 标注是否仍在，不能假定存在。DynamicReplica 未解决 split 映射前继续排除。

训练 RGB 生成不要求用户提供全量人工 mask/depth/pose/caption。新增优先级是小规模可靠的动态测试标注、原视频父 ID 与时间戳；若做相机/物体控制，才需要对应的有效轨迹与可见性。视频估计相机位姿不是真实 WASD 动作，不能据此宣称学习了行动后果。需要新 teacher 时可由用户下载后离线带入，当前失效 Stream tracker 不作为阻塞整个项目的依赖。

当前主任务不需要新增人工相机、深度、分割、检测、动作或文本标注。RGB与冻结编码器产出的特征/latent提供监督；可用的索引、帧顺序、采样步长和数据划分支持训练。精细相机对齐仅用于后续明确的控制/几何评估实验，不能作为RGB生成的准备门槛。数据不足应首先检查有效窗口覆盖和任务一致性，不以无法提供额外标注为主要失败解释。

数据准备单独见 [DATA_PREPARATION_REQUEST_20261013.md](DATA_PREPARATION_REQUEST_20261013.md)。本计划依据仓库实现、已完成的 stage51/52 结果与截至今日核对的原始论文；不以此前讨论中的设想代替实验事实。

## 1. 结论与研究问题

当前成果还不足以支撑一篇有竞争力的方法论文。已有可复用的重建表示、完整训练链路和失败定位证据，但还缺少：稳定的未见场景视频生成、相对强对照的收益、几何表示贡献的受控证据，以及经过验证的方法贡献。

“VGGT 特征可以去噪并解码 RGB”不再适合作为主要创新。GLD 已包含 VGGT RGB 生成，Latent Riemannian Flow Matching 直接建模 VGGT 特征，GAE 已实现紧凑几何表示的 RGB/几何联合读出。因此本项目应该回答：

> **在真实动态视频中，几何预训练表示能否让有限数据、有限算力下的未来 RGB 生成更容易，同时保留可测量的空间结构？如果当前不能，什么表示性质或学习机制妨碍了它？**

建议首篇范围：已观察图像或短历史 → 短未来 RGB；相机轨迹作为独立的可选条件实验。先取得短片段质量与机制证据，再决定是否延伸为世界模型。交互、回访、长期记忆、文本控制不是本轮必备模块。

论文成立可以有两条证据路线，但均未得到验证：

1. **方法路线**：发现具体障碍，提出针对性改进，在相同数据/预算下同时改善 RGB 质量与几何或数据效率，并解释为何有效。
2. **系统性研究路线**：通过充分的匹配对照，得到可复现、跨域、能指导几何表示生成的新规律。仅整理失败日志或展示换数据后的提升不够。

若只有“终于能生成”，应把它作为重要基线成果；不能直接升级成“几何世界模型”的论文主张。

## 2. 已知事实与未解决问题

| 链路 | 已确认 | 尚不能下的结论 |
|---|---|---|
| 表示 | 冻结 StreamVGGT aggregator；C256=geo128+texture128，18×18；无时间压缩 | C256 不是原始 VGGT 特征，也不是所有信息都来自 VGGT |
| 外观支路 | learned texture encoder 直接编码训练 RGB，与几何码共同生成；不是 decoder 的 GT RGB skip | 不能把当前系统写成“纯 VGGT tokens-only” |
| 几何读出 | 有池化特征重建和关系损失 | 当前没有接回原生 depth/camera/point heads；特征 MSE 低不证明几何可读 |
| 时序编码 | StreamVGGT global attention 已采用 frame-causal mask；压缩和 texture 编码逐帧 | 不存在代码层面已证实的“后续帧污染前帧”；joint cache 不等于泄漏 |
| 重建 | 新 AE 配对评估改善，跨域 mean-domain PSNR 25.872；SpatialVID 子集约23.09 | 跨域均值不等于所有街景25.9；重建改善不保证生成改善 |
| 生成 | 831.3M SceneFlow；中期 raw71609 有部分可辨认短 I2V，仍有运动/形变问题 | 最终模型不代表最佳模型；三个采样点不足以找出全程最好 |
| 失稳 | BF16 EMA 缺陷已定位并改为FP32；raw137104确有后期退化；三rank loss一致上升 | EMA不是全部原因；具体后期优化机制尚未定位 |
| 数据 | 17,450 train来源×4窗口=69,800完整缓存；SpatialVID只用8,192街景+256replay | 不是全HQ；旧FullHQ与新实验的数据、latent负担、模型规模都不相同 |
| 任务混合 | 原采样57.5%来自标为temporal_valid=False的来源；标志未进入flow缓存；缺真实Δt/task条件 | 不代表静态多视图无用；不能单独据此解释125k后的collapse |
| 参考 | 原生Wan14B已有四个有效样例，证明该街景任务可有清晰输出 | 不是同预算表示消融，也不证明把Wan权重塞进当前latent即可成功 |

对应实现：`models/scene_rae.py`、`streamvggt/models/aggregator.py`、`train_scene_pipeline.py`。结果详见 [raw/EMA复核](SCENE_RAW_EMA_RESULTS_20261012.md) 与 [数据和方法复评](DATA_AND_DIFFUSION_REASSESSMENT_20261012.md)。

**本轮必须分开回答三个问题**：训练是否稳定；当前明确任务是否学得会；几何表示是否比替代表示更有用。一次同时改数据、AE、长度、模型和loss，无法回答它们。

## 3. 第一优先级：一个干净的生成任务

### 3.1 数据与输入输出

- 主训练先取 SpatialVID 连续街景：单一相机流、无shot切换、可验证时间间隔；保留行人/车辆等动态，不筛成静止背景集合。
- pilot 先1,000–2,000个训练来源组、8k–16k不同窗口，100–200个未见开发来源；按父视频/scene而非窗口划分。具体可用数由清单审计决定。
- 从1个已知帧→4个未来开始；多历史对照为4个已知帧→**同样4个未来、同一时间原点**。两组最后已知帧相同；前者不获得额外三帧。
- A/B必须共享future target的编码上下文、归一化与decoder策略；初步保留“末观察帧+future”的目标定义，只增加可见history条件。额外history采用显式观测编码/reference策略，不能顺便重编码target。若无法保持一致，应明确是条件与表示共同变化的系统比较，另补隔离消融。
- 主实验扩到8个未来。按SpatialVID实际标注间隔约5Hz估计，4/8未来约0.8/1.6秒，但必须保存实际timestamps，不能把估计值硬编码为事实。
- RGB、518分辨率、C256、18×18、831M网络先固定。不同时加网络宽度、时间压缩和新AE。
- 首轮以I2V/历史条件为明确任务：观测条件始终存在，取消该任务的reference dropout；不把大量无caption样本当T2I前置训练。各新对照使用相同的改动。相机条件另起配对实验。
- A/B/C训练和采样都显式关闭future rays/pose及text。现代码默认可能读取这些字段，不能只在文字中称“RGB-only”而沿用入口；cache里有字段不代表该实验允许模型访问。
- 条件仅来自已观察RGB；生成从未来latent的纯噪声开始。评估必须剔除被直接放入视频的已知帧。
- 固定采样器、步数、CFG和开发样例；初始可沿用Euler32/CFG1，单独少量32/64步检查数值采样误差。不能给不同模型各挑一套有利设置却称严格对照。

### 3.2 不让旧问题混入新结论

保留当前AE作为第一组固定表示，不默认再花三天重训。FP32 EMA、raw/EMA双采样、分任务日志、后期稳定性观测属于基础修复，不作为新方法增益。

公平方法对照默认使用相同初始化策略与种子配对，从零训练flow。已有71609等raw快照只做诊断或明确标注的质量warm-start分支，不能让一臂继承长训练、另一臂从零再比较数据效率。

第一阶段不要求“先T2I成功再T2V”。此前无条件图像分支的caption覆盖与数据多样性不支持把它当必经质量门槛。是否保留图像联合训练，应以后续单独消融决定。

## 4. 先定位机制，再决定方法

以下探针优先复用已保存权重与小样本，不重跑旧memory64/trajectory/subspace大实验。旧实验的结果是先验资料；新探针只填当前C256与新任务的证据缺口。

### P0：优化与解码误差定位，必须做

1. 固定同一批train/dev样本，对raw71609和已保存110603/124641/126964/final做有限诊断，缩小后期退化区间。不要只检查一张首步x0图；高噪声x0本来可能接近条件均值。
2. 新训练记录噪声分桶的未加权x0误差、实际加权loss、pre-clip梯度范数、clip频率、update/weight范数比、输出latent尺度、raw/EMA距离；按任务/域分开。旧快照可复算预测/输出/参数诊断，但没有保存的历史梯度、clip频率和真实更新比例不能追溯恢复；加载后重新做的诊断梯度必须另标，不能冒充当时遥测。
3. 先在由同一GT加噪构造的配对去噪任务中提取真实预测残差，按噪声段分组，与等RMS各向同性高斯、匹配通道方差的扰动对比，观察RGB与独立几何误差。自由生成相对单一GT的差不能直接都当作预测错误。原AE已有jitter，不能把加高斯噪声当新方法。
4. 用 `GT geo + predicted texture` 与 `predicted geo + GT texture` 的oracle替换定位敏感支路。**这些含GT的图只用于诊断，不能计入生成结果或展示成可推理能力。**
5. 对train/dev同步做纯噪声生成：训练集也生成差偏向优化/表示问题；train好dev差偏向泛化，但需结合样本覆盖和条件歧义，不能单指标归因。

若稳定性是主要障碍，先用短配对实验验证LR/参数更新幅值等最小修复。不要同时堆EDM2、谱损失、GAN、蒸馏、球面flow。现有C256经学习压缩与归一化，不等同于原始归一化VGGT四层所在的球面空间。

### P1：历史与表示上下文，低成本探针后决定是否立项

当前因果目标实际可写为：

\[
z_t^{causal}=P(E(C,I_1,\ldots,I_t)_t),
\]

其中 (C) 是已观察历史，(I_1,\ldots,I_t) 是从当前观察时刻看尚未生成、但在目标序列中较早的帧。其相关性是合法的联合建模，**并不是已经证明的训练/推理错误**。

契约检查：保持已观察RGB不变，删除/替换更晚future，prefix特征应在数值容差内不变。单独编码prefix与整窗prefix输出也应一致。这个零效应测试不是论文创新。

研究探针：固定同一目标RGB，只改变它之前的合法历史长度、间隔、窗口参考帧策略；分静态背景/动态物体、低/高相机运动测特征、RGB与几何变化。历史提供更多信息本来就可能改善几何，不能把全部变化称为有害漂移。

只有探针支持该问题，才比较：

\[
z_t^{fixed}=P(E(C,I_t)_t),\qquad z_t^{frame}=P(E(I_t)_t).
\]

三个目标定义都由同类型DiT**联合生成所有未来**。fixed仅排除了较早未知target参与编码；不意味着逐帧独立生成，也不自动改善时间一致性。

立项条件与限制：

- 改善必须体现在未见场景RGB、运动和几何，不能仅latent loss下降。
- 固定anchor不自动固定metric scale；不得逐目标单独Sim(3)对齐后宣称无漂移。只允许观测context确定的一次对齐，并同时报告未对齐结果。
- 新上下文改变encode映射，需要新cache/stat/codec兼容验证；不能把旧decoder遇到分布变化的失败误判成目标定义失败。
- 可先用同架构、平衡接触三种特征的共享codec检验；若分别训练codec，要报告重建上限和各自训练成本。旧AE只作为原任务基线。
- 编码每个`C+I_t`可能更慢，必须计入预处理NPU小时。
- LRFM已有单目标条件表示接口，这个公式本身不是首创；可能的贡献是针对**真实动态联合生成**的机制、设计与可复现收益。
- 若因果表示已经稳定，或fixed丢失重要几何/运动信息，就停止把这条解释当主线。

### P2：只有解码敏感性明确时，才做误差适配的表示/decoder实验

候选为用开发训练样本上的真实flow残差校准decoder或codec鲁棒性，同时保持clean RGB和几何读出。必须对照“无扰动、现有高斯jitter、同强度协方差匹配扰动、真实残差”，防止把加大一般正则化误称新机制。

这是第二候选，**不与P1同时展开长训练**；一般的噪声增强、decoder微调已有直接先例：[LV-RAE](https://arxiv.org/html/2602.08620v1)已分析高维latent的解码敏感性并用噪声增强改善decoder，单用这些不足为创新。若只改decoder，冻结encode映射和flow可直接测作用；若改encoder，则必须重缓存、重算统计并重训匹配flow。所有扰动来自train，不能用test拟合误差。

若两个机制均无证据，下一步应是更强表示/教师对照或明确转向预训练生成器路线，而不是继续给无效模块起名字。

## 5. 最小实验矩阵：什么必须比较

| 编号 | 目的 | 控制方式 | 本轮优先级 |
|---|---|---|---|
| A | 当前表示能否在明确任务稳定生成 | 当前SceneAE，1历史→4未来，修复后训练；单街景域 | 必须 |
| B | 单图缺少运动信息是否关键 | 与A同目标、同末观察帧、同模型家族；4历史→4未来 | 必须；需实现多历史 |
| C | 几何表示是否真正有优势 | 与B同RGB/目标，像素VAE表示；同预算与相近DiT容量 | 必须；接口需实现 |
| D | 有证据的表示改进 | P1或P2中至多一条，与对应未改基线配对 | 探针支持后 |
| E | 几何先验 vs 通用语义 | 强语义RAE（如DINO系），同任务/数据与训练预算 | 论文必补，首轮可先小规模 |
| F | 相机运动条件的作用 | 同一有pose子集、同预算训练有pose/无pose模型；另测推理时pose扰动 | 若主张可控制，必须 |
| G | 静态多视图是否有益 | 只街景 vs 已核验静态辅助；显式task/time或独立辅助任务 | 基线稳定后，不先重混七域 |
| H | 纯VGGT信息 vs RGB纹理支路 | 当前dual-stream vs同容量VGGT-only输入；重训相应codec并报告上限 | 若主张“仅VGGT特征”，必须 |

VAE的时间压缩会改变条件/目标边界。第一轮可用逐帧像素VAE做清楚的表示对照，不能宣称因此胜过强视频VAE；论文系统表还要有合适的视频VAE对照。使用视频VAE时必须按其合法时间分组、单独处理已知条件，不能让observed压缩块读到future。匹配RGB时长，报告token数、容量和总算力；无法完全匹配则明确称系统对比。

新DINO/像素codec并非现成零成本。所需适配、decoder训练、缓存、归一化都要计入预算。旧R7含时间压缩/legacy统计，适合作为历史系统参照，不是只换encoder的纯消融。

C/E同时改变预训练数据、架构与表示，因此支持表示系统的受控比较，不单独证明“几何预训练”具有因果效应；H只隔离RGB纹理支路。要使用更强因果措辞，还需设计保持其他因素的有效几何信息干预，并确认没有顺带损坏外观或降低任务难度。F中推理时null/shuffle可能是分布外输入，只能作为敏感性检查；真实未来pose提供额外信息，受控任务与自由I2V分表报告。

GLD/LRFM/GAE是最近邻工作。能获得兼容实现/权重时在其适用的静态NVS设定做外部对照；不把它们硬改成动态视频后再称官方结果。原生Wan属于质量参考；若用其生成权重训练，则另列“预训练生成器辅助”分支，不与从零flow的贡献混写。

## 6. 论文所需的效果与证据

### 6.1 三个层次，不能混为一个目标

| 层次 | 要得到什么 | 预期边界 |
|---|---|---|
| 运行交付 | 不丢中间权重、可恢复、同口径指标/样例、可解释实验记录 | 可以通过实现和预演努力保证；硬件/外部服务异常仍需恢复 |
| 第一轮质量目标 | 未见街景4–8未来具有可辨认结构与合理运动，明显减少网格/色块；跨连续保存点稳定 | 合理研发目标，尚不能保证实现，更不承诺达到14B原生Wan |
| 论文竞争力 | 匹配对照下有可重复的RGB/几何或效率优势，且有机制证据 | 需多seed、独立测试、强baseline；15天一轮通常不足以补齐全部 |

可预注册的**研发效果目标**：在不恶化运动真实性和RGB感知质量的前提下，主要几何误差相对降低约10%以上；或达到相近质量所需独立训练来源/训练NPU小时显著减少，争取接近一半。数字只是决定投入的目标，不是已有结果、统计显著性标准或论文录用门槛。最终优先给出效应量、置信区间和完整折中曲线。

不能以“更静止所以L1更低”“挑了几个成功seed”“重建PSNR更高”代替生成优势。

### 6.2 冻结评估协议

- 开发集用于选方法、checkpoint和采样设置；论文test预先封存。主域争取300–500个未见父来源，每来源2固定窗口、2–3采样seed；按父来源bootstrap。
- “未见”要追溯当前codec及其warm-start来源的train，不能从已参与AE训练的8,192街景中重切一块便声称未见。优先原held-out与未参与相关模型训练的新HQ父来源，并排除近重复；旧flow参照若见过该数据需单列。记录各阶段数据可见性，无法核实的基础模型预训练覆盖单独披露。
- 分布指标争取1,000–2,000个不同held-out片段，报告样本量敏感性。短4/8未来不直接套不同长度的FVD榜单：验证特征提取实现和时长要求、统一真实时间/帧数；不重复填帧伪造长视频。需要更长片段的标准协议放在后续16未来等扩展，另测显存与耗时。
- RGB：感知质量、分布距离、temporal artifacts；L1/PSNR只作配对辅助。随机seed样本画廊、失败比例必须报告。
- 动态：与copy/低成本warp基线比较运动幅度、静止复制比例、前景轨迹/遮挡后身份、相机/物体运动分层。不能以错误更小的“冻结世界”冒充视频生成成功。
- 几何：有GT子集+独立模型从生成RGB估计。若用VGGT监督，不能只让同一个VGGT裁判；相机控制同时测路径遵从和RGB质量，报告估计失败率。
- 自由未来与单一GT不同并不自动是错；深度/轨迹配对误差优先用于重建、受控NVS/pose任务或确定性可对齐部分。对未规定未来的I2V，以分布、运动与内部几何一致性为主。
- 原生几何读出要先验证完整多层grid/特殊token/heads输入。当前18×18 pooled feature恢复不能直接被称为接回原始37×37 geometry head。若未实现，只能写“生成RGB的几何一致性”，不能写“latent原生联合输出几何”。
- 小规模盲测可用100–200对片段、至少3名独立评价者；随机左右顺序，分画质/运动/结构提问，避免仅挑成功样本。

### 6.3 从本轮走向论文，必须补足

1. 一个连续真实主域的主结果，另一个**真实**域的独立验证。只在街景成立则主张限定街景；Point/Spring合成集不能代替第二个真实动态域。
2. 当前几何表示、候选、强语义RAE和像素/视频VAE的公平表。对预训练数据和辅助teacher逐项披露；“无预训练视频生成权重”不等于“没有任何外部预训练”。
3. 最关键一对至少2个独立训练seed，最好3个；采样seed不是训练seed。成本高时先重复核心比较，不平均撒在所有小消融上。
4. 嵌套25%/50%/100%父来源数据曲线；运动分布保持可比。同训练曝光与同NPU小时分别分析，codec/缓存成本另列并计入总成本。固定codec已见100%本域时，只能称“固定codec下的flow数据效率”；若主张端到端数据效率，codec也必须遵循同一数据子集，或全部臂使用共同外部codec训练池。
5. 主机制消融与反例、clean重建上限、随机样例、训练/测试差距。若候选只让目标更模糊或运动更小，则不算有效。
6. 若使用geometry-aware标题，必须有超出外观相似度的可复核空间证据；若使用interactive/world model标题，另需动作响应、长rollout误差、遮挡/回访等证据，本轮不默认承诺。

对应建议图表：主流程图；机制探针图；质量/几何主表；数据与算力曲线；历史/pose/表示消融；随机视频与失败案例。缺哪项，就收窄哪项主张。

## 7. 三节点15天预算与安排

沿用此前资源作为**下一轮集群预算**：3节点×8张910B×15天=8,640 NPU小时。元数据整理与新接口本机测试先做，尚未就绪不能把现有51直接当新实验启动器。下面是资源封套，不是已经可执行的启动脚本。

已运行的速度依据：AE9,126更新/72.06h；缓存69,800窗口/约12.8h；image16,394更新/24.15h；video137,104更新/180.12h。约4.73s/video阶段更新包含25% image更新，不能外推为纯视频速度。新历史长度、表示与目标长度需要重新实测。

| 时间 | 资源与上限 | 工作及交付 |
|---|---|---|
| Day1，24h | 24卡，576 NPUh | 真实完整形状预演、恢复/退出/双读写；小缓存、P0/P1探针与性能测量；冻结pilot合同 |
| Day2–4，72h | 3路各8卡，1,728 NPUh | A/B/C三个短pilot；配对目标与曝光，持续输出样例。并行编排未通过时改成同24卡拓扑依次运行；C表示接口不兼容则先修复或延后C，不能用拓扑切换掩盖 |
| Day5–10，144h | 24卡，3,456 NPUh | 稳定基线 vs 探针支持的候选；没有方法信号则比较几何表示 vs 最强替代表示。**144h先扣实测缓存/codec适配/切换时间，余量对称分给两臂**；只有准备均已完成才是各72h |

若缓存/适配超时，优先保持对照完整、缩减独立窗口规模，不能挪空统一评估或只保留候选训练。大型新AE重训与3组完整训练seed通常进入第二轮；先由第一轮信号决定，不预支“必能成论文”的长期预算。

P1若需要新codec，其训练计入Day5–10这144h，不能暗中免费增加三天；若将挤掉有效主比较，则本轮只做小探针，正式P1移到下一轮。按旧速度100k窗口约需18.3h/24卡只是量级估计，新codec/context可能更慢。原地DDP从8变24不会降低每卡参数/optimizer内存，不能当作OOM解决方案。

### 7.1 并行、公平性和显存

- 当前51 hard-code 3×8；三路8卡需要独立launcher、rendezvous端口、namespace和rank组。此编排尚未实现。
- 原global batch96=24×micro1×accum4。8卡若匹配同batch，accum12；不把batch32与96的结果只归因于模型。记录更新数、独立来源数、样本曝光、目标帧数、token数、NPUh。
- 当前flow的cosine LR按墙钟预算进度、EMA按step变化。新对照应预先固定按optimizer update或累计样本曝光定义的LR/warmup，并以相同曝光定义EMA衰减；墙钟只作资源停止上限。否则即便batch相同，IO/吞吐差异也会让同曝光位置的LR不同。此处是待改实现，不是声称旧训练已采用该协议。
- 同曝光结果与同NPUh结果分别取曲线上的对应点；表示速度不同就不能声称二者同时严格相等。必须报告停止时各自真实曝光。
- 8→24卡改变world及RNG/cursor，不能当精确resume。正式主对照同初始化从零最好解释；必要warm-start需新namespace与明确成本计账。
- rank0旧峰值AE33.14GiB、image20.49GiB、video23.92GiB；FP32 EMA额外常驻约1.55GiB/卡。加法只能估计，eval/恢复/新history的峰值需实测；不按显存余量直接翻倍模型。
- 缓存现latent本体下限约116GB，另有ray/text。内存2-shard LRU不是磁盘清理。先1–4k小切片适配，再扩8k–16k pilot；主轮按实测可扩约100k窗口，300k不作为15天硬承诺。
- 只改decode数学上可复用encode latent，但当前identity含全AE；需正式区分encode/decode身份才能安全复用。改encode/context/预处理则全部相关缓存与统计重建。

### 7.2 如果要补成论文，时间如何安排

首轮结束先看证据，不自动接着消耗另一轮算力。若已得到可观看基线和可重复的方法信号，且codec/数据接口就绪，可按**再一轮同量级15天**估算验证预算：核心两臂第二训练seed最多144h；25%/50%数据曲线四个短训练最多96h；强表示缺项、第二真实域与统一评估共96h；24h余量，合计360h。各短训练仍按实际曝光/算力报告，不能当完整长训练。

这只是可行性估算，不是已经申请的额外资源，也不保证所有缺项刚好填满。新几何头/新codec若还没实现，或要求3个完整训练seed与长回访，应增加准备/计算时间，或收窄论文主张。数据整理与工程开发、训练后的人工盲评/论文写作时间另列，不能藏进“15天训练已完成论文”。

若总资源严格只有本轮15天，就优先交付短动态生成的一个核心比较、机制探针和可复现记录；暂不同时承诺全面数据效率、跨域领先与可交互长世界模型。第一轮没有优势时，先复核/转型，不为凑论文继续填大表。

## 8. 工程完成定义与保存策略

### 已具备/已本地修复

stage51全阶段跑通，stage52完成216例复核；双路径读写、提交收据、坏数据跳过、DI_throughput、阶段ckpt、FP32 EMA修复、退出有界清理均有代码基础。最近cleanup与FP32 EMA长训练峰值还未在新集群运行验证。

### 新计划开跑前要补齐并实测

1. 多历史condition和时序位置/Δt、有效mask；当前flow只读取anchor首槽，不是调history参数即可。新增显式condition白名单：A/B/C禁止训练及采样读取future rays/pose/text，F另立合同。
2. task、physical time、parent/scene/camera、observed/target IDs、encoder context、anchor/decoder策略进入cache身份；未知值显式缺失。
3. 三路8卡编排、VAE/语义RAE接口、以更新/曝光为轴的LR/warmup/EMA；技术不兼容清楚退出当前作业，不能静默拿错cache。
4. 新完整网络/条件长度下，前反向→首次optimizer状态→eval→保存→新进程恢复；验证下一批/下一更新与不中断对照。短CPU测试不能替代真实NPU/HCCL。
5. 一份存储不可用、另一份损坏、SIGTERM、部分cache提交、中断恢复、guard启动与停止、全rank有界退出。只保留本作业helper，不影响其他任务。
6. `DI_throughput: ... tokens/s/npu`必须持续回显；另记录目标帧/s、clip/s、计算/IO/评估/保存时间、显存峰值。保活负载不算有效吞吐，不以不同token口径直接比较效率。
7. 冻结manifest：代码commit、数据split、codec/encoder/decoder SHA、cache/stat identity、优化器/种子/采样设置、有效坏样本清单、先验来源。

保存初始方案：每小时weights和固定开发样例，每3–6小时完整optimizer/RNG/cursor恢复点；在下面的容量/上传预演后冻结实际频率。各阶段保留latest/final/选中的candidate。检查点大小约旧full11.64GB，FP32 EMA后预计full13.30GB、model+EMA6.65GB。最近恢复点需双份确认；payload完成后发布receipt。远端保留本轮周期快照，本地仅回收已双副本确认、无人读取的旧文件。

**容量与实现待办**：上述weights/full双周期尚未实现，现代码一次save同时写full latest和周期weights，需要拆计时器。按两轮3路各72h加144h主比较的上界，共576模型小时；每小时6.65GB weights约3.83TB/远端副本、双副本7.66TB，尚不含full/cache/视频。启动前核实配额和上传速度，冻结一致的保存策略；预算不足时weights可调2–3h、每小时预览照常，不能让checkpoint IO吞掉训练时间。full恢复点须有明确保留的不可变周期版本，不能只有不断覆盖的latest；至少保留各阶段起点、定期完整恢复点和选定健康点。不会删除历史实验远端产物来腾空间。

质量差只记录、选择健康中期checkpoint并影响后续科研投入，不作为自动阻止后续阶段的门槛。NaN、错数据契约、坏权重则属于技术错误，需保存现场并恢复/修复，不能假装成功。

## 11. 主要依据

- [GLD，含VGGT附录C1](https://arxiv.org/html/2603.22275v1)：几何特征域视觉生成的直接先例。
- [Latent Riemannian Flow Matching](https://arxiv.org/html/2607.19120v1)：原始VGGT归一化特征的流与几何/RGB读出。
- [GAE v2](https://arxiv.org/html/2609.24981v2)：紧凑几何codec及匹配生成对照；不能重复主张“几何表示可生成”。
- [VGGT-World](https://arxiv.org/abs/2603.12655)：未来几何预测与RGB视频生成的任务边界。
- [Improved RAE baselines](https://arxiv.org/html/2605.18324v2)、[VideoRAE](https://arxiv.org/html/2607.14088v2)、[V-RAE](https://arxiv.org/html/2608.13556v1)：强表示基线与视频任务设计。
- [GRACE](https://arxiv.org/html/2610.10524v1)、[DuoMatching](https://arxiv.org/html/2610.03543v1)：借助现有生成先验的备选路线，不能当作本项目从零训练已有效的证据。

文献说明创新边界和可借鉴方法，不证明当前失败的唯一原因；本文方法候选仍需定向新颖性检索和实验。

# Scene 短历史续写实验结果

本轮已正常完成，获得了一版可观看的街景短历史续写基线。多数验证场景能保持建筑、道路和人物的整体结构，连续帧中能看到相机移动及人物行走的延续；不再是普遍碎片化的场景。局部运动、近景遮挡、细节和部分曝光仍失败。建议保留 step31,069 的 FP32 EMA 作为当前参考，online 表现接近。

这个结论严格限于观察四帧、生成五帧、约 0.625 秒未来。它证明当前冻结表示与 flow 的组合可以完成较强条件的短时 RGB 预测；没有证明单图生成、长时滚动或几何控制已经成功。

## 相同任务下的配对结果

每个 case 先平均两个采样 seed，再以 64 个 case 汇总。128 个采样结果不是 128 个独立场景，也不是两个独立训练重复。

| 未来五帧指标 | 新接口下未适配的 71609 online | 本轮最终 online | 本轮最终 EMA | 参照 |
|---|---:|---:|---:|---:|
| 与 RAW 的 L1 | 0.21735 | 0.08940 | **0.08913** | AE 0.04381；COPY 0.10496 |
| 历史到预测首帧的帧差 | 0.18171 | 0.07978 | 0.07902 | GT 0.06990 |
| 预测未来内部帧差 | 0.12323 | 0.05897 | 0.05903 | GT 0.07141 |
| Laplacian 绝对值 | 0.04010 | 0.03164 | 0.03137 | AE 0.03152；GT 0.06886 |
| 归一化 latent std | 0.94405 | 0.98737 | 0.98637 | 未下载逐例 GT latent 重算 |

最终 EMA 的 L1 在 64/64 case 上低于新接口下的未适配起点，51/64 低于重复最后一张输入帧。相对 COPY 的均值改善约 15.1%。EMA 与 online 的均值差仅 0.00027，未出现旧 BF16 EMA 那样的明显评估失真。

**0.21735 的起点已经使用新 4→5 接口。** 原 71609 没有接受过这种 clean-prefix 训练，适配它本身就是这轮学习内容。因此相对起点约 59% 的 L1 降幅，不能写成“比历史单图视频模型画质提升 59%”。历史 stage52 的 1→8 任务、文本条件和评分帧范围都不同。

L1 只是对一条记录未来的像素距离。生成运动帧差在 54/64 case 低于 GT，逐 case 比值中位数约 0.807；结合时序可见部分运动较保守，但帧差不是速度或光流。GT 帧差最高四分位的 16 例全部优于 COPY 的 L1，说明收益不只来自近静态案例；这仍不是动态真实性评分。

## 实际画面中的进步与失败

四列原视频依次是 RAW / AE / GENERATED / COPY。GENERATED 的前四帧直接显示输入 RGB；观看时必须从 frame4 开始判断生成能力。

- case000、008、019、024、048、056 等保留了街道布局、建筑轮廓、车辆及人物的主要外观。case024/048 的连续帧能看到人物位置变化，case000/008/056/063 能看到相机运动延续，区别于最后输入帧静止复制。
- 动态人物仍会发生重影、肢体模糊或不准确的位置变化，例如 case004/007/011/037/047。清楚的背景不等于人物动作正确。
- case003 的运动较保守；case010/036/038 的近景遮挡或大视差不可靠。case036 的 seed101 与 seed202 质量有明显差异，不能只展示较好的种子；case010 两个种子均出现不同的局部结构扭曲。
- **case041 的曝光异常已经存在于 AE 重建。** RAW L1：AE 0.29821，生成 EMA 0.34676，COPY 0.05801。由真实历史 RGB 切到生成帧时的突然变亮，一部分来自 codec，不能全部归因于 diffusion。case015、005 也有较大的 AE 误差。
- 最终生成的高频幅度接近 AE oracle，低于原始 RGB；视觉上也有纹理软化。它提示需要拆开 codec 与生成误差，但一个 Laplacian 标量不能证明严格的 decoder 质量上限。

整体上可以将这版作为后续实验的短历史续写参考；不能把所有 64 例标成“质量通过”，也不应再把本轮概括为“仍然完全训不出来”。

## 训练过程是否继续退化

抽查 rank0、1、8、16，各有 3,107 条训练记录，无重复 step 或非有限值。首 1,000 步与最后 1,069 步的抽查记录聚合如下：

| 指标 | 前段 | 末段 |
|---|---:|---:|
| loss | 0.12022 | 0.09387 |
| 未加权 x0 MSE | 0.07528 | 0.05608 |
| 高噪声区间 MSE | 0.08467 | 0.06231 |
| prediction std | 0.9467 | 0.9551 |

记录内最大梯度范数 0.638，未触发裁剪；末期 EMA 距离下降。三节点没有 Traceback、OOM、异常重启或空卡两小时回收的迹象。末期 DI_throughput 约 1,475 future tokens/s/NPU，包含中途保存和评估等待；守护进程工作不计入吞吐。

必须在固定 8 case、seed101 上比较时间趋势：source 0.20890 → step1845 EMA 0.10881 → step14991 0.10346 → final 0.10028。该子集约 92% 的总 L1 下降在第一轮 1,845 步监控前已经发生，之后继续改善但幅度变小。20k 以后接近平台，没有上次后期整体崩坏的现象。

最终全 64 case 的 0.08913 不能直接和中途 8 case 的约 0.1003 比较并称“最后突然进步”。低误差主要来自评估集合变化。当前证据不支持仅延长同配置训练就会再有大幅提升。

## 对项目路线的含义

这轮提供了一个有用的正结果：现有 VGGT 派生 C256 表示，加上已有 0.831B flow，可以在真实街景中生成基本合理的短时未来 RGB。因此，“表示天生完全不能扩散”不是当前证据支持的解释。

这次同时改变历史条件、数据抽样域、优化器、EMA 精度及 LR；没有单变量消融，不能把成功唯一归因于四帧历史，也不能据此认定混合数据是唯一问题。模型仍包括学习到的 RGB texture 分支，不是仅凭 VGGT 原始特征完成生成，更没有验证几何头读出。

下一步建议先保留当前 AE 和 final online/EMA，围绕已得到的基线补两个小范围验证：

1. 相同未来目标、表示、初始化、曝光量下的历史条件对照，区分观察历史带来的收益与其他适配变化，避免直接比较 1→8 和 4→5 两种难度。
2. 使用生成帧作为后续条件的滚动续写，检查错误何时积累。下一窗口要重新编码对应 RGB 历史并维护 anchor/context 语义，不能直接把旧因果 latent 的任意中间段当作新的独立窗口。

另对 case041 等样本做小规模 AE 曝光/细节回放，定位源数据与 codec 误差；暂不因这些个案重训整个 AE。长视频、相机控制和几何优势应在这些验证之后单独证明。本次只审阅结果，没有启动新训练或更改训练实现。

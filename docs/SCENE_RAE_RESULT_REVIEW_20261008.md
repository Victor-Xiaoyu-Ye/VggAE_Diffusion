## 重建已改善，生成仍不合格

固定验证 AE 的平均域 PSNR 从 19.379 升至 **25.872 dB**。终点同案例样本均值为 25.810 dB，旧 R7 为 24.380 dB，配对平均 **+1.429 dB**。`ae/complete.json` 选择同为 9,126 步的 `best_joint.pt`。多数 RAW/AE 画面对照显示场景内容保持清晰。OmniWorld 比旧 R7 低 0.450 dB；SpatialVID 仅高 0.330 dB。各域新/旧均值如下。

| 来源 | 新 AE PSNR | 旧 R7 PSNR | 配对变化 |
|---|---:|---:|---:|
| DL3DV | 29.223 | 27.469 | +1.754 |
| MVS-Synth | 24.555 | 22.648 | +1.907 |
| OmniWorld | 24.448 | 24.898 | −0.450 |
| PointOdyssey | 23.299 | 21.331 | +1.968 |
| ScanNet++ | 28.935 | 27.003 | +1.932 |
| SpatialVID | 23.090 | 22.759 | +0.330 |
| Spring | 27.552 | 24.609 | +2.943 |

单图训练 loss 中位数约 0.448→0.327，最终固定样例 AE 重建 L1 为 0.0367；末期 16,394 步的 27 例自由生成均出现重影、拼贴及局部纹理破碎，早期 2,042 步抽查的 4 例也有类似问题。固定样例 `raw_l1` 0.2637→0.2640；**无条件自由生成与一张指定真实图像的像素距离本身不是可信质量指标**，画面检查支持“没有得到可靠单图生成”的结论。

视频固定 27 例的未来帧 L1 最低是 **9,185 步 0.1637**，末期升至 **0.1732**；复制首帧基线为 **0.1347**，终点仅 3/27 例更低。固定样例 AE L1 为 0.0392。训练 loss 在 110–120k 步中位约 0.144，125–130k 为 0.241，135k 后为 0.399，末端还有尖峰；说明后段存在明显退化风险。9,185 步的 `weights_step0009185.pt` 仍在 OBS，但在四例同案例的三时点视觉对照中，较早权重也未出现可靠的结构稳定性，不能因为它的像素 L1 最小就称作最佳视频。`video/complete.json` 当前选择最终 checkpoint，未按视觉质量择优。

视频样例三栏依次是 RAW、AE、GENERATED；**GENERATED 的第 0 帧是直接拼入的真实参考 latent**。只看第 1–8 帧才是在评估扩散器。最终 27 例中可见部分街道/建筑大致轮廓，但室内、合成场景和游戏对象常在前几帧变成纹理拼贴，出现物体消失、重复立面和时域结构漂移。不能把第 0 帧的清晰度或 AE 重建质量记作生成质量。这个观察覆盖本次固定 27 例与所述三时点，不代表所有训练分布。

最终 27 例中仅 **4 例有 caption，16 例有相机条件**；SpatialVID 4 例均无相机，DL3DV 4 例仅 1 例有相机。现有样例无法支持“已经验证 geometry-aware 生成”的结论，也没有相机控制的对照实验。缓存 69,800 个窗口，视频训练的抽样次数按 rank 0 记录外推 24 rank 约 3,619 万、约每窗口 519 次；这是**训练抽样次数**，不是独立视频数量。当前证据不足以把后段 loss 升高归因于某一个坏来源。

## 对项目的判断与下一步

本轮排除了“AE 根本重建不了 RGB”和“大量数据文件缺失”这两个直接解释。生成的瓶颈已在**单图自由采样**出现，视频端又有后期 loss 和样例退化。当前不能从已有日志唯一定位是 DiT 对高维 RAE latent 学习不足、采样器误差、输出 latent 偏离 AE 可解码分布，还是这些因素叠加；把这种视觉现象直接称作 latent OOD 仍是待测假设。

下一步先用现有冻结 AE、图像终点和视频 9,185/终点权重做一轮**推理与统计诊断**，不用启动新的 15 天训练：

1. 在相同固定验证 latent 上，按多个噪声 `u` 比较真实加噪后的单步 `x0` 误差、其 RGB 解码及各通道/空间频率误差，分离训练目标拟合与自由 rollout 失败。
2. 比较 32 步 Euler、更多步数/Heun、EMA 与原始权重，以及视频早期/终点同种子的 latent 范围和解码画面，排除采样器/EMA 与权重选择问题。
3. 对训练与生成 latent 做均值、方差、频谱、跨通道相关性和 decoder 扰动敏感度对照，验证“好重建但生成 latent 难扩散”的具体环节。
4. 先取得可辨认且稳定的单图自由生成，再扩展视频与几何控制；之后专门保留有相机条件的验证子集，加入有/无相机、真实/扰动轨迹对照。单次固定种子的像素 L1 只作辅助，质量决定还要看多种子视觉与结构指标。

## 结论

本轮完整结束，修正坐标后的 AE 辅助监督没有形成可靠的主输出增益。
区域加权 SFT 是更有用的普通基线：在帽子改色、帐篷编辑及部分背景保持上
有实际改善；再加入 AE 监督，整体指标与多处画面反而退化。

这不等于 AE 或可解码表示在所有任务中无效。本轮验证的是 native VACE
隐状态的 edited-target AE 特征/decoder-RGB 辅助监督，AE 不参与最终推理渲染。
它不是后续“decoder 校准的编辑传输与实际输出写回”的实验。
Stage62 的机制证据仍需单独观察；本目录没有 Stage62 结果。

L1 是 [0,1] RGB 的每片段均值。编辑/保持区域来自 source-target 差异代理，
不是语义分割、运动或几何真值。PSNR 与 specialist edited target 比较，
也不是指令遵循分数。直接复制源视频的平均 PSNR 是 **21.1945**，高于表中
所有方法，因此绝不能仅用该指标选出“最好的编辑模型”。

主要配对观察：

- SFT 比当前原生指令协议高1.8543dB，keep误差低36.3%；这一收益属于任务微调。
- AE 相对 SFT 低0.9387dB，keep误差高22.7%；PSNR胜10/24例，keep更好10/24例。
- 区域加权相对 SFT 高0.4758dB，keep误差低21.0%，keep更好20/24例。
- 在相同区域权重下，加AE低0.8253dB、edit误差高6.69%、keep误差高18.86%；
  PSNR和edit误差各仅胜4/24例。这是本轮不支持AE增量收益的直接证据。

按片段配对 bootstrap（20000次，seed20261105），AE−SFT 的PSNR差95%区间
为[-1.993,0.010]dB，区域AE−区域SFT为[-1.341,-0.330]dB。
区域SFT−SFT的keep L1差为[-0.0271,-0.0058]。
这些仅描述当前24片段的变化，不包含训练种子方差；不据此声称普遍因果结论。

## 源视频粗框诊断

四例床、帐篷、蝴蝶、帽子使用相同人工源框，无未来target进入推理条件。
它是额外条件协议，不是纯文本指令跟随能力的公平替代分数。

框确实可减少一些框外伪色，例如Native床/蝴蝶背景。但Native床仍未改成
lavender，SFT帽子仍未明显改棕，帐篷有只改窗口的情况；区域组在框内把
帐篷形状大幅重绘，AE蝴蝶还出现明显灰色矩形背景。说明“在哪里改”与
“改成什么、如何保留物体形状和动态”必须分别解决。

Native四例PSNR从纯文本平均17.54左右升至21.8029，但并不意味着编辑都成功。
额外条件下AE也未形成总体优势。注意：框协议的region指标以用户框计算，
纯文本以source-target差异计算，**不能直接把两套ROI均值相减来宣称提升**。
全帧PSNR及同帧视觉可比较，但都需同时检查编辑执行。

### Detached对照的实际限制

CPU精确等价测试此前通过，但这次NPU实际运行不逐位等价。SFT与detached
第1步flow完全相同（0.13005422280790904），LoRA grad norm已略有差异
（0.00719665 vs 0.00719348）；第2步采样已有小差别，1000EMA均值差0.1735dB，
某些后期RAW单例差异更大。因此不能把负对照写成严格同轨迹。

检查代码，readout有实际detach、head与LoRA分别clip；各arm重新设置LoRA
初始化seed，训练noise/sigma/drop用逐步显式generator。尚无证据表明
detached意外接收了辅助梯度。NPU融合attention/归约和附加head改变计算路径
是可能原因，未用权重逐步对齐证明。后续若继续做精确梯度因果实验，应使
两组保留同样模块/计算并检查初始化与早期LoRA更新；不要凭CPU测试宣称NPU
也完全确定。本轮单次结果可用于选择方向，不足以排除所有数值/种子影响。

## 1. 建议与边界

**不再把“VGGT 替代 VAE”本身作为论文的主要论点。优先研究：跨帧几何关系在压缩和去噪中是否保留，以及这种保留能否提高自由生成质量。**

先建立能正常采样的 diffusion，再决定几何方法；两者共用评估集，但不能用方法创新掩盖训练尚未跑通。原生视频模型保留 VAE 的路线是质量参照和可能的最终方案。R7 路线是表示研究候选，不能因为已经投入很多 AE 实验就自动成为主线。

用户已允许两条路线，以质量优先；资源为 48 张 Ascend 910B，沿用 ModelArts、OBS、已有启动和恢复约定。本文没有发起训练、修改缓存或改写模型代码。

## 2. 两篇 RAE 工作具体覆盖了什么

VideoRAE 将冻结的视频基础模型特征转成可重建、可生成的 latent，包含层级特征聚合和表示对齐。V-RAE 使用冻结视觉编码器、时间池化和视频解码器，评估多种编码器，而且已经包含未来视频预测。因此，它们不宜概括为“仅让 video generation model 对齐 visual foundation model”。[VideoRAE](https://arxiv.org/html/2607.14088v1)、[V-RAE](https://arxiv.org/html/2608.13556v1)。

对我们而言，下列说法均不足以单独建立贡献：换成 VGGT；训练 RGB decoder；在 foundation features 上训练 DiT；添加几何特征 cosine；从重建推广到未来预测。

相关工作还进一步收窄了空间：

| 工作 | 已覆盖的方向 | 对本项目的约束 |
|---|---|---|
| [VideoREPA](https://github.com/aHapBean/VideoREPA) | 视频表示的时空关系蒸馏 | 普通 pairwise relation alignment 不能直接称为新方法 |
| [Geometry Forcing](https://geometryforcing.github.io/) | 几何特征对齐用于视频生成 | “用 VGGT 监督 diffusion”需要更具体的区别 |
| [CAMEO](https://cvlab-kaist.github.io/CAMEO/) | 多视图生成中的对应关系注意力监督 | Correspondence loss 本身已有近邻工作 |
| [MoVideo](https://arxiv.org/abs/2311.11325) | 深度、光流 warp、遮挡 mask 辅助生成 | “已有表面传播＋新区域生成”也不是未经探索的想法 |
| [WorldReel](https://bshfang.github.io/worldreel/) | RGB 与几何、运动联合生成 | 简单扩展 geo/texture 双流或联合输出不够 |
| [WorldWarp](https://arxiv.org/abs/2512.19678) | 几何缓存、warp 与按区域变化的加噪 | Warp 加不同噪声日程不能单独宣称新颖 |

这些工作并不证明项目没有空间；它们要求贡献落实到一个明确失败机制、一个针对性设计和公平的实验证据。本文提出的是研究假设，不作“首次”“无人做过”的结论。

## 4. 先把 diffusion 训合理

### 4.1 一次只验证一层

固定已经完成的 t1 geo112/tex80 AE、训练统计量和数据 ID。目标暂用绝对 future latent，避免同时引入旧 residual cache 的语义变化。

1. **Oracle sampler**：让真实采样器每一步返回固定目标 x0。检查实际 dtype、时间网格、归一化、首帧恢复与 RGB 解码能否返回 AE 重建。
2. **确定性网络接入 sampler**：用已成功的 g(anchor) 作为与噪声、时间无关的 x0。对终点为 1 的 data-time Euler，正确实现应在最后一步回到 g(anchor)。先验证实现，不把它算作概率模型成功。
3. **随机噪声 n1**：同一 pair、每步重新采噪声；从多个未见噪声自由采样。单一目标条件下应接近同一目标，不以“seed 越不同越好”为目标。失败时检查逐时间误差和训练/采样轨迹，不能据此继续增加未来帧数。
4. **16 个训练 pair 记忆，再独立留出评估**：训练集记忆和跨场景泛化分开报告。通过后才扩至多帧、较大数据集。

当前 25/26 的 preconditioned / velocity 路线值得完成，但实现存在不等于它已跑通。应先做这组验收，再比较 V-RAE 配方。

### 4.2 V-RAE 的 x0 与当前 plain-x0 不同

本地只读核对了 `D:\workspace\V-RAE`，HEAD 为 `a7783e8ebdb59a3bac3dbb5388a6eadcd274162b`。关键源文件是 `src/vrae/models/dit/transport.py`，不是仅根据论文摘要推测。

用噪声时间 u 表示：

```text
x_u = (1-u) z + u ε
v_hat = (x_u - z_hat) / max(u, 0.05)
v_target = (x_u - z) / max(u, 0.05)
L = ||v_hat - v_target||²
  = ||z_hat - z||² / max(u, 0.05)²
```

所以这个实现虽然输出 x0，优化的是加权 x0 误差，最大权重为 400。它不是当前 plain-x0 的无权重 MSE，也不能把这一截断目标笼统视为所有时间点都完全等同 ε−z。参考实现还包含 base 分支损失，不能把省略该分支的最小移植称为完整复现。[官方代码](https://github.com/V-RAE/V-RAE)。

它采样 logit-normal 噪声时间，再做 `s*u/(1+(s-1)*u)`；本仓库多处是 uniform 数据时间 t，经同形公式偏移后使用 `x_t=(1-t)ε+t*z`。设 s=3，前者噪声时间中位数 0.75；后者对应噪声时间中位数 0.25。两者可以各自成立，但不能直接复制 shift 超参数。

建议在同一个已经通过记忆测试的模型上做小型 2×2 对照：

| | Uniform noise-time，shift=1 | Logit-normal noise-time，固定 shift |
|---|---|---|
| plain x0 MSE | 基础对照 | 仅改时间分布 |
| 截断 velocity-space loss | 仅改损失权重 | V-RAE 风格的两个组件 |

第一轮统一 x0 head、条件路径、模型宽度、随机种子、batch、训练步数、EMA 和评估 sampler。先不加 RGB、geometry auxiliary、horizon weighting 或内部 guidance。此矩阵是机制对照，不是完整 V-RAE 复现；之后再独立验证宽输出头、base 分支与参考采样器。

参考 shift 的 latent scalar-count 规则对当前 t1、18×18、192 维，K=1/4/8 分别约为 3.90/7.79/11.02，但这是形状换算，不是验证过的最优值。R7 的压缩、相关性和有效维度不同，不应照搬 Cityscapes 配置中的 27。

本地 V-RAE Cityscapes YAML 与论文训练表的 batch、步数/epochs、学习率日程有差别。论文的多帧上下文未来预测也不同于本项目首帧 I2V。必须固定选用的代码版本和配置，不把自己的单帧结果与论文表格直接比较。

### 4.3 Wan 的角色

保留原生 VAE、原生输入输出头和原生 I2V 条件接口的模型用于建立质量参照。在原生采样通过后，再做相同数据上的普通微调与几何方案对比。

现有 WanCompactAdapter 随机输入/输出投影旁路原生 patch embedding/head。这种适配可以研究，但不能假设加载 backbone 后即可在 R7 空间继承完整视频先验。不要同时重训表示、随机替换输入输出接口、全量更新 Wan，再把失败归因于某一个部件。

如果最终研究选择从头训练的 RAE-DiT，应增加相同 generator/budget 的 semantic-RAE 对照；如果选择原生视频模型微调，应增加同等参数量的普通微调对照。两条路线的绝对质量和匹配实验分别报告。

## 5. 推荐的研究假设：几何关系保持的生成表示

**假设：几何 foundation model 的收益，取决于跨帧表面对应关系能否穿过压缩瓶颈，并在去噪产生的 latent 中被恢复；仅保持 RGB 重建或特征 cosine 不能保证这一点。**

这一假设不是已有结果。需要先判断当前失败发生在哪里：

```text
原视频 → 原始 GFM 特征 → 压缩 latent → AE 重建视频
                                  ↘ diffusion 预测 latent → 生成视频
```

在同一组视频、同一协议下测四处的几何能力：原始特征、压缩特征、重建视频、生成视频。再按噪声强度，测预测 clean latent 的几何能力恢复曲线。

至少区分：静态背景随相机运动、独立运动物体、遮挡后重现、新出现区域。只用相机深度重投影解释动态物体会产生错误监督。新露出区域没有之前的真实对应，必须有 visibility/null 处理。

当前实现的两个实际障碍：

- 本地 StreamVGGT 类只保留 aggregator，不能直接把它当成可输出深度、相机和轨迹的完整模型。需要恢复兼容的冻结几何 heads，或训练并严格控制容量的独立读出器。
- geo/tex 在 temporal block 经过全通道卷积，最终前 112 维不是受结构保证的几何变量。暂时不能直接按通道实施“geometry-first denoising”。

### 5.1 最小可行的表示实验

先做 frozen-feature probe，不重训大 AE：在分离的训练子集拟合相同容量读出器，在场景隔离的测试集测对应关系、深度/位姿可读性与可见性；比较原始 GFM、当前 R7、一个语义 RAE。读出器不能强到自己重新学习完整几何模型。

若压缩导致几何能力明显丢失，再做一个针对性 codec 变体：**让时间压缩保留跨帧对应关系，而不只对固定图像网格上的特征做混合。**

具体候选是 correspondence-aware temporal pooling：可对应表面的特征按对应关系聚合；不可见/新出现内容保留独立表示；解码所需的位移与可见性必须由 latent 承载。先用 teacher 对应关系构造 oracle 上界，再训练可在生成端恢复这些关系的模型。

这是比单独添加 cosine 更明确的结构假设，但并非已经确立新颖性的方法。必须与固定网格池化、相同参数量的自由 attention pooling、2D optical-flow 对齐比较；否则收益可能只是多了容量或普通运动补偿，与 3D foundation model 无关。

生成端不能偷偷使用目标视频的轨迹、深度或 mask。教师可以离线监督完整训练视频；推理时只能依赖首帧/文本和生成状态，未来关系必须预测或共同生成。若只有 oracle geometry 能工作，这条路线尚未完成。

### 5.2 什么时候才扩展 diffusion 方法

先保留同一个已训通的 DiT，单独更换表示，证明几何保留有价值。只有当表示端保留了几何、而生成端仍系统性破坏它时，再考虑去噪时的关系恢复目标或结构化交互。

几何关系应从预测 clean latent 读取，不能把高噪声特征强行当作准确点图。监督需要置信度、遮挡处理和坐标/尺度约定。对于静态背景可测相机重投影；动态前景应测轨迹或动态几何，不能施加刚体一致性。

这一步的可信贡献应是“针对压缩和去噪中的具体几何破坏机制，设计并验证了有效方法”，而不是罗列几何 loss、warp、双流、memory、RL 等已有模块。不要现在就同时实现所有组件。

## 6. 48×910B 下的实验顺序与停止条件

| 阶段 | 资源安排建议 | 继续条件 |
|---|---|---|
| A：链路诊断 | 优先单卡或单节点；复用 25/26 的 staging/resume | oracle、det 接入 sampler、随机噪声 n1 均能解释和通过 |
| B：表示证据 | 离线特征与小读出器；不启动大 DiT | GFM 在目标数据确有几何优势，并能定位压缩损失 |
| C：受控生成 | 固定小数据集、相同模型；2×2 配方对照 | 多 pair 能记忆，留出自由采样开始有合理内容和运动 |
| D：方法验证 | 基线、语义 RAE、几何表示变体；可用各 16 卡，需集群允许分组 | 同预算几何改善且视觉质量不退化；多个 seeds 可重复 |
| E：规模化 | 胜出路线使用 6×8；沿用 OBS 与恢复契约 | D 通过后才扩大数据、时长与模型 |

不预估尚未实测的 NPU 吞吐或训练天数。先记录实际峰值显存、clips/s、编译与缓存开销。跨配置比较使用相同有效 global batch、样本曝光量和加速器小时，不能只比较 step。若需要并行独立实验，要确认调度能力；48 卡硬件并不自动等于已有并行实验启动器。

大数据训练要同时留一组覆盖遮挡、动态物体、相机运动的诊断切片；仅增加相似短街景不能支撑长期表面一致性的论点。首帧 I2V 为主任务，多帧上下文作为明确分开的辅助设置。

停止/改向条件：

- oracle 失败：修实现；不重训 AE。
- oracle 成功、随机噪声 n1 失败：修训练/采样契约与条件路径；不扩大数据。
- 原始 GFM 在目标数据无可靠几何优势：调整数据/teacher，或撤回该表示论点。
- 压缩几何变好而同预算生成无收益：不能声称几何保留导致更好生成。
- 仅 oracle future geometry 有收益：证明了上界，未完成可用生成模型。
- 几何分数变好但视频几乎不动、清晰度下降：失败；增加 motion-matched 对照并检查指标作弊。
- 几何 RAE 在合理对照下持续落后原生路线：以生成质量为先，转向原生模型方法，保留负结果。

## 7. 如何使最终结论可被相信

质量：自由采样视频、感知/分布指标、盲评；有限样本 FVD 只作诊断，不报夸大排名。PSNR 可用于 paired memory/reconstruction，不能单独评价多解 I2V。

几何：跨帧对应误差、背景重投影、遮挡重现后的身份/纹理稳定性；运动幅度配平。尽量使用独立于训练 teacher 的评估器，并保留有真实几何/轨迹标注的受控数据切片，避免只证明“更像 VGGT”。

机制：表示压缩率、latent scalars、模型参数、训练预算配平；比较 clean 与不同噪声水平下的几何可读性。额外容量、重建差异和上下文帧数作为混杂因素单独检查。

本项目最值得争取的最终结论是：**在相同生成任务和预算下，保持可测量的跨帧几何关系比只保持语义/重建更有利于生成，且能定位并缓解遮挡、重现和动态运动中的具体错误。** 能否形成这个结论，取决于上述实验，不能靠架构名称预先保证。

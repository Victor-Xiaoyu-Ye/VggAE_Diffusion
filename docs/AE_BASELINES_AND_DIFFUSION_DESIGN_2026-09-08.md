# 从已有 AE 重建基线建立视频 diffusion

本文件是 2026-09-08 多轮纠正后的当前设计依据，优先于此前质量审查中的路线排序。后续已实现独立DiT/trainer和28/29/30启动入口，参见 `WINDOW_DIFFUSION_RUNBOOK.md`；没有新训练效果声明。

## 1. 当前任务与研究边界

用户要求：以已有接近 PSNR 25 的多版 AE 为重建基线，思考适用于本项目的 diffusion；25/26 只能选择性参考，不能作为训练底座；V-RAE 的 setting 不同，只能借鉴思想。资源仍是 48×Ascend 910B，使用已有 ModelArts、OBS、数据 staging 和恢复约定。

主任务是首帧条件下生成未来视频；若使用 caption，必须显式记录并在各对照中一致。不是多帧历史预测、给定未来相机轨迹的新视角合成，也不自动扩展成 4D 输出任务。用户此前允许保留原生 VAE 的路线作为候选，但本轮首先以已完成 AE 为起点，不另起大 AE 训练或直接放弃这些表示。

建议首先研究固定 9 帧、1 秒窗口（实际采样契约最终以各 checkpoint 为准）。第一帧作为条件，其余 8 帧联合生成。暂不增加长视频 rollout、任意历史长度或 variable-noise diffusion forcing，它们是不同的训练任务。

## 3. 对现有系统的完整理解

```text
视频 / 固定物理时间采样
    → 冻结 StreamVGGT aggregator 特征
    → CompactCompressor 几何分支 + RGB TextureEncoder
    → R7 通道瓶颈与因果时间 codec
    → latent（18×18，通常 C192）
    → 生成模型
    → 同一个冻结 temporal decoder / RGB decoder
```

几个会影响 diffusion 设计的事实：

1. 生成目标是经过多级有损压缩、混合的 R7 latent，不是原始 2048 维 VGGT 特征。C192 的性质必须实测，不能直接套高维 RAE 的结论。
2. geo/tex 在 temporal codec 经普通全通道卷积混合，最终 latent 的前112维不是被结构保证的纯几何。基线应联合生成全部192维。
3. R7 encoder 采用因果机制；首帧 latent 应可由单独首帧获得。新基线仍需要针对每个真实权重验证“单帧编码 anchor ≈ 完整 clip 编码 anchor”，避免使用带未来信息的条件缓存。
4. RGB decoder 有非因果时间注意力。联合生成全部未来，再一次解码完整9帧是自然契约；训练 t1 却仅生成一个未来再重复到9帧，是单帧诊断，不是最终任务。
5. 旧 Wan adapter 更换输入/输出投影并绕过原生 patch embedding/head，还涉及时间与目标语义变化。加载 backbone 不等于在 R7 上保留了可直接使用的视频先验。
6. 既有 `geometry-motion cosine` 是压缩特征差分代理。它可以记录，但0.95不应阻止本轮已认可 AE 的新研究对照；旧门槛与旧产物仍保留，新实验用独立 namespace/准入声明。
7. 实际此次 OFT 镜像枚举为10000视频，划分 train9935/eval64/overfit1。文档中的146万 clips 是另一规模/数据布局，不能视为当前任务已可访问的训练量。

## 4. 旧 diffusion 的证据边界

- 历史 t1 完整未来窗口运行到6K，自由采样质量仍差。这说明“取消时间压缩”本身没有解决问题，不说明 t1 表示不可能生成。
- 旧 Wan7K→14K 的 x0 指标改善而实际采样变差，说明应按自由采样评价，不能单看去噪 loss。
- `git show 2f2fe0e:train_causal_video_diffusion.py` 明确采用 velocity 输出与积分；当前同名文件是 x0 版本。历史运行不能为当前整套代码背书。
- 当前 `CompactLatentDiT` 的 WideHead 是 MLP 投影，不等于 RAE 的浅层宽 Transformer DDT head；源码顶部关于 AdaLN 不合适、时空交互收益小的文字只是历史实验判断，不是通用规律。
- 25/26 未完成且出发点是诊断，只能引用局部数学/测试。27 的状态残留 running 也没有提供任何生成成功或失败的新增证据。

结论：目前有可用重建起点、历史运行基础设施和明确的失败样例，但没有一个可以原样继承并认定合理的生成基线。应按组件建立新训练契约，不能只选一个编号继续加参数。

## 5. 文献能提供什么，不能提供什么

| 一手来源 | 可借鉴思想 | 对我们的适用边界 |
|---|---|---|
| [RAE](https://rae-dit.github.io/) | latent 的维度、噪声和 denoiser 容量要相适应 | 我们192维/token，历史主干768/1152维，不能用“宽度小于token维度”解释全部失败；不强制加2048宽头 |
| [Scaling RAE](https://arxiv.org/abs/2601.16208) | 噪声调度的重要性与架构技巧的收益需按规模验证 | 大规模T2I里宽头收益变化，不证明本项目一定不需要宽头；支持做消融而非照搬 |
| [JiT](https://arxiv.org/abs/2511.13720)及[参考 denoiser](https://github.com/LTH14/JiT/blob/main/denoiser.py) | clean prediction 与优化空间可分开设计；直接输出数据不等于无权重MSE | 它是像素图像生成，不能直接移植网络或超参数；可用来论证候选目标 |
| [History-Guided Video Diffusion](https://arxiv.org/abs/2502.06764) | 对历史条件、未来噪声和引导方式做显式设计 | 我们固定一个首帧，不需要立即引入任意长度历史和逐帧噪声 |
| [VideoRAE](https://arxiv.org/abs/2607.14088)、[V-RAE](https://arxiv.org/abs/2608.13556) | 重建质量不等于生成适用性，时间压缩值得独立评价 | 不作为本项目code base，不复制上下文长度、latent维度、架构与完整recipe |

这些来源支持候选设计，不能证明该设计已适用于 R7。尤其没有文献能直接保证“PSNR25 AE + 某个通用配方就会生成好视频”。

## 6. 建议的新 diffusion 基线

### 6.1 首先固定任务与形状

生成条件为首帧 c，caption 为独立可选条件；同组实验的 caption 完整性、dropout 与 guidance 必须一致，不能 silently 回退全空文本。

| 表示 | clean anchor | 一次生成的未来 | 最终RGB |
|---|---|---|---|
| t1 C192 | 1×18×18×192 | 8×18×18×192，2592 tokens | 原契约9帧 |
| t2 C192 | 1×18×18×192 | 4×18×18×192，1296 tokens | 原契约9帧 |

不对原始 latent 再做2×2 patch合并，避免同时引入额外空间瓶颈。t1/t2位置编码中的物理时间须按各 codec 的因果组边界确定；不能把一个t2 latent误当作一张普通RGB帧。

目标使用绝对 future latent。anchor 是条件而不是 loss 目标，不重建真实未来条件，不默认 residual-cache，不按未经证实的 geo/tex 通道切开训练。所有 AE 模块冻结。

### 6.2 模型结构

新建适配 R7 的条件视频 DiT，不整套沿用07/13/25/26，也不直接加载V-RAE网络。

建议初始容量为 hidden768、12个时空block、12heads；最终参数数目以实现打印为准。这是完整未来窗口生成模型的起点，不是保证最佳的超参数。若容量实验需要，后续再比较1024/16层，避免开局就随机适配1.3B Wan。

每个block包含：future tokens 的全时空 self-attention、对静态首帧 memory 的 cross-attention、时间调制与FFN。caption存在时加入独立文本条件。空间/时间位置使用可适配18×18和两种时间长度的编码。

首帧 memory 只由真实首帧构建，保留到各层；不让它在输入端和噪声混合后就失去独立通路。future之间允许双向交互，因为目标是联合生成窗口，不是自回归逐帧预测。

全时空attention有计算成本，但也允许运动物体跨位置建立联系。若910B实测成本过高，可比较交替空间/时间attention；不能在没有对照时直接沿用“固定位置时间attention已足够”的旧判断。优先复用仓库已审查的NPU算子适配，不引入只支持CUDA的依赖。

### 6.3 归一化与统计

复用已有原始latent缓存的前提是AE、采样和tensor契约完全匹配。每个AE重新核实训练集统计，anchor与future分开，保持可逆的frame/channel标准化；明确这是初始工程选择，不是对Gaussian目标分布的要求。

统计仅由训练split计算，以FP64 CPU累加、FP32保存和应用。不要从单pair统计推导正式数据分布，不把旧R5/R6 residual统计用到R7 absolute。先检查每通道/时间位置std、尾部、有效秩和mean-only基线；暂不增加PCA/全白化等新的表示变换。

评估同时报告RAW latent、标准化latent与RGB，记录mean-only/copy-anchor。接近单位方差或很高的原始motion cosine都不能单独作为成功标准。

### 6.4 预测目标与采样

建议主候选：网络输出 clean latent，采用截断加权的x0损失；另保留相同网络、仅改变输出解释与目标的 direct-velocity 对照。不是继续25/26的两种小模型实验。

明确使用噪声时间u：

```text
x_u = (1-u) z + u ε
z_hat = fθ(x_u, u, anchor, text)
L = mean((z_hat-z)² / max(u, τ)²)
```

初始τ=0.05是候选数值，不是已验证结论。采样时u从1到0，使用 `(x_u-z_hat)/u`（只在u>0求值），最后一步Euler，不调用u=0的除法。截断只用于训练权重；积分的具体定义须独立单元测试，不能误把不同代码里的clamp混用。第一轮固定64步Euler作可重复基准，另用同一checkpoint比较更多步与Heun，避免将积分误差和学习误差混淆。

初始时间分布可用LogitNormal(0,1)、shift1；针对R7另做shift3对照，而不是复制论文的17或27。训练分布与采样时间网格作为两个独立配置记录，不能因为两者都有shift字段就绑定修改。

第一轮不加geometry/RGB辅助、未来帧加权、复杂guidance或冻结期切换。等基本内容和运动合理，再逐项增加。这样才能回答改进来自表示、目标、条件路径还是辅助约束。

## 7. 数据与训练规模

不再把主要预算投入n1→n16的串联。保留少量数值和小数据健康检查用于发现实现错误，但训练主任务从开始就是完整未来窗口。

先在固定训练子集上确认全窗口前向、反向、保存与真实采样，再进入当前可用9935视频训练。所有AE使用相同视频ID与物理采样时间；验证集与训练集按源视频隔离。caption若不能可靠提供，则这轮明确做无文本I2V对照，而不是伪装成T2V/I2V联合训练。

48卡可以先运行一个基线，也可以在调度允许时分成两组24卡比较t2v2/t1geo112。对照有效global batch例如96：48卡×每卡1×累积2，或24卡×每卡1×累积4。实际microbatch与activation checkpoint由显存测试决定，不估计未经测量的吞吐和天数。

t1的future token数是t2的两倍，完整self-attention的代价差异更大。因此分别报告相同样本曝光量下的质量，以及相同NPU小时下的质量，不能只按step宣布谁更优。

按样本曝光量和wall-clock确定阶段预算，定期保存真实自由采样。9935视频、global batch96时，2000步已约19.3轮曝光，6000步约58轮；训练loss下降也可能是过拟合。扩展数据前先核实真正可访问的全量元数据与视频，不能直接沿用146万clips的注释。

## 8. 如何判断 diffusion 合理

分开评价三件事：

1. 实现健康：输入/目标/condition身份、无未来泄漏、训练与采样同一参数化、梯度和EMA、恢复一致性。
2. 生成质量：留出首帧的自由采样是否有真实内容、清晰度和合理运动，是否使用条件、是否优于复制/均值基线。多解I2V不能只按逐像素PSNR判断。
3. 几何收益：在同等视觉质量和运动幅度下，表面形状、跨帧对应、背景刚性与动态对象一致性是否改善。

每次固定同组首帧、caption和多个noise seeds；同时保存RAW参考、AE重建、copy、online生成、EMA生成。AE重建是表示参照，不是所有感知/分布指标的严格上界。去噪按噪声区间记录，优先看其与自由采样的关联，而不只按单一x0 loss选best。

现在只有9帧短窗口，不急于把少量样本FVD当论文排行榜。需要固定时间重采样/评估预处理，避免因repeat/interpolation改变运动产生虚假优势；先用可解释视频对照与运动/对应指标，规模足够后再报告有可信统计量的分布指标。

## 9. 差异性从何而来

本项目最有价值的现成对照是：**RGB重建相近，但时间压缩与几何特征保留不同的AE。** 它允许测试几何表示的生成价值，而不把所有差异归因于重建清晰度。

先问：t2v2和t1geo112谁更好生成？t2v3提高几何代理却降低重建，是否更有利于运动一致性？同为t1，geo112相对均分是否带来超出重建误差的收益？这些是待测问题，不是默认答案。

如果几何收益存在，再针对生成中损失的关系做方法设计，例如约束预测clean latent保留可见表面的跨帧关系。若收益不存在，要区分“teacher在数据上不可靠”“压缩抹掉了关系”“denoiser没有利用关系”。不能只增加一项cosine然后命名为geometry-aware。

普通几何特征对齐、光流warp、对应关系attention、RGB/geometry联合生成都有近邻研究：[Geometry Forcing](https://geometryforcing.github.io/)、[MoVideo](https://arxiv.org/abs/2311.11325)、[CAMEO](https://cvlab-kaist.github.io/CAMEO/)、[WorldReel](https://bshfang.github.io/worldreel/)。应围绕可证实的失败机制做贡献，不能预先宣称首创。

几何评估避免只用训练teacher自评分；静态背景可以验证相机重投影，动态物体需要独立轨迹/对应指标，遮挡区域必须处理有效性。运动越小往往越容易“稳定”，所以要有motion-matched比较。

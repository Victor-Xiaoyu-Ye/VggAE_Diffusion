# 项目转型：把画质目标与表示假设分开

2026-09-22。用户要求发散讨论目标与转型。本文件是研究建议，不代表用户已批准替换架构、增加实验或停止现有任务。本轮没有修改训练代码、启动或停止集群任务。实验事实沿用同日 `FULLHQ_RESULTS_AND_CAMERA_PIVOT.md` 的快照，没有刷新训练进度。

## 判断

建议保留“几何能改善可控视频的质量与一致性”作为方向，取消“RGB 必须在自训 VGGT/R7 空间里从零生成”作为项目成立的前提。

目前同时承担了新 tokenizer、从零学习广泛真实视频分布、单首帧预测、交互世界状态四项任务。缺少成功的共同参照时，任何失败都可以被另一部分解释，项目难以形成可证伪的中心问题。重建 PSNR 不是这四项任务之间的通行证。

这不证明 R7 不可生成，也不证明 scaling 无效。已审查的 1.65B 实验约训练了 1.93 个缓存数据遍历。另一方面，loss 下降也不保证完成 100K 步后会出现好视频。

## 三个需要撤销的默认推论

1. **真实视频可重建，不代表条件分布容易生成。** 编码时看到了完整真实视频；生成时首帧不能确定场景背面、相机运动或动态物体行为。更多重建细节可能增加目标复杂度；不能据此断言当前高维空间必然不可学习。
2. **VGGT 来源不等于可操作的几何状态。** 投影、压缩、时序混合后的 R7 尚未证明保留可读出的几何关系。`geo`/`tex` 名称不是解耦证据。相机一移动，同一面墙换了图像 token 位置；没有显式运输或查询机制时，DiT 仍须学习大范围特征迁移和视图形成。
3. **观察视频加相机控制不等于完整交互动力学。** SpatialVID 可监督记录路径下的视图变化，但不直接提供同一状态、不同动作的反事实结果。它适合受限场景探索；碰撞、物体操作、多人动作归因需要另外的数据与验证。legacy codec 的整窗统计也不满足直接用作前缀稳定状态的要求；固定窗生成本身仍然可以合法使用它。

配对 L1 只是一项诊断：合理未来可以与记录不同，复制首帧或模糊结果也可能得分不错。现有预览确实有变形，不能将失败全部归咎于指标。

## 具有不同目标的转型选项

| 路线 | 实际交付 | SpatialVID 的支持与缺口 | 优先级判断 |
|---|---|---|---|
| 少量历史观测后的轨迹视频补全 | 看过 4–8 帧后，按给定路径生成短视频；复用已知内容、生成新暴露区域 | 可构造真实历史/未来监督；任意大幅偏离记录路径没有直接 GT | 最适合画质主线，先小视点、短时、低动态 |
| 视频再摄影 | 输入完整视频，为同一事件换镜头 | 动态事件已有观察；另一相机的同步真实视频通常缺失 | 易形成直观产品，但更像 V2V 编辑，现有竞争很强 |
| 接收新观测后纠正场景假设 | 新真实图像推翻错误几何/外观，修改应传播到后续其他视角 | 连续视频可做逐步揭示；真实回访和场景身份仍需筛选 | 可研究，必须依托已经达标的 RGB 生成器 |
| 生成可渲染场景资产 | 从稀疏图像补全场景，随后用渲染器交互导航 | 适合低动态场景；动态街道、遮挡和大尺度漂移困难 | 若实时交互比视频动力学更重要，可单独立项；910B 栅格算子须评估 |
| 继续做生成友好的几何 tokenizer | 对照不同表示的生成难度、几何保留和 decoder 鲁棒性 | 原视频够做表示研究；必须固定生成器和预算 | 是另一篇表示研究；不适合作为近期最快获得好画面的主线 |

若目标改成仅预测几何/特征，VGGT-World 是直接相关工作；这会主动放弃当前“好 RGB”的核心要求，不能用几何结果替代画质验收。[VGGT-World](https://arxiv.org/abs/2603.12655)

## 文献边界：不要把组合组件当成新贡献

| 已核验一手来源 | 对我们意味着什么 |
|---|---|
| [MIRA](https://arxiv.org/abs/2607.05352) | 报告 5B、1 万小时游戏、多个玩家的动作条件；同为 RAE 不代表任务信息量、模型与训练预算相同。也不能把高速游戏物理简单说成容易。 |
| [GEN3C](https://arxiv.org/abs/2503.03751) | 三维缓存按目标相机渲染、生成未见区域已经成立为方法路线。 |
| [WorldForge 官方实现](https://github.com/Westlake-AGI-Lab/WorldForge) | 已有 VGGT warp 与原生视频模型 repaint，无需训练。直接移植可以是基线，不能宣称新的核心方法。 |
| [World in World](https://arxiv.org/abs/2609.11548) | 冻结视频模型读取相机/时间标记的视觉证据，是更近的控制接口工作。 |
| [Mirage](https://arxiv.org/abs/2606.09828) | latent 空间的三维持久记忆已有研究。 |
| [GIM-World](https://arxiv.org/abs/2606.02436) | 相机可查询的几何监督、压缩历史为隐式记忆也已有研究。 |
| [Closing the Loop](https://arxiv.org/abs/2607.21848) | pose/depth 对应驱动的历史检索和回访一致性已有人做。 |
| [C3](https://arxiv.org/abs/2512.05927) | 生成置信图与校准不确定性本身不能作为新意。 |
| [3D-Belief](https://arxiv.org/abs/2605.11367) | 新观察更新三维信念、多假设补全也已是明确研究目标。 |
| [VidSplat](https://arxiv.org/abs/2605.11424) | 生成视图补充稀疏重建并以置信加权更新，不是空白路线。 |

本轮没有确认一个无人涉足的论文方向。较值得检验的问题是：**真实视频中的几何推断有误差、生成内容缺乏真实证据时，新观测能否纠正旧错误，并把纠正传播到未再次观测的视角，同时不破坏已经观察到的外观？** 这是具体假设，不是已确认创新；尤其必须与 3D-Belief 等进一步作实现与评估层面的比较。

例如：模型先把遮挡后的墙面生成成窗户；相机前进后真实图像揭示那里是墙。真正的状态修正，应使之后相邻视角也不再出现那扇窗，而不仅是把最新输入图像复制过去。

## 建议的质量主线

输入从单首帧放宽为短历史和目标相机轨迹。历史帧应全部早于预测起点，1/4/8 帧实验必须预测同一未来；不能把靠近或位于目标段的额外帧伪装成历史。

VGGT 从允许的观察中估计结构、对应关系和几何可靠性。由场景表示向目标相机投影出已知内容及覆盖/遮挡提示。保留预训练视频生成器的原生 codec、输入输出接口与采样定义，为缺失内容和动态部分提供外观先验。不要重演“替换原生 latent 接口但把加载权重视为完整先验”的实验。

几何置信度不等于校准过的生成正确率。错误深度、位姿尺度和动态区域必须允许被拒绝或作为软条件；强行复制不可靠投影可能比不加几何更差。未知区域则允许多种合理补全，不要求与唯一记录逐像素一致。

历史中的真实观察与模型自己生成的内容应保留来源；后者可以维持当前想象分支的一致性，但不能因为反复送入 VGGT 就自动成为独立证据。纯生成模式下没有新真实观察，系统也不能声称识别了想象场景的真实样貌。

候选研究必须证明 VGGT 比更简单的单目深度/pose warp 或普通 RGB 历史更有价值。在相同 RGB 主干、条件帧数、token 预算和训练预算下，分别比较无几何历史、depth/pose 条件、VGGT 几何关系及其增量。若替换成普通深度后效果相同，应接受 VGGT 不是核心贡献。

## 有限的下一步，而非继续扩大诊断项目

已经实现的 stage50 保持为一项有上限的相机条件对照。不能因本文件而自动取消任务，也不能在其结果之前默认再扩大 camera 训练。成功仅说明记录路径条件有效；失败不能否定所有几何路线。

新增方向建议先以固定的 12–24 个场景完成端到端画质筛查，覆盖可投影的静态结构、遮挡显露和少量动态区域。可复用已保存的完整原生 I2V 样例作为质量参照；不应为报告凑齐而默认重新跑整套昂贵的原生审计。

关键对照是同未来的 1/4/8 帧历史、复制/几何投影/完整生成，以及条件为零时是否恢复原生主干行为。先看整个视频是否清楚、运动是否符合路径、已见纹理是否保留，再在共同可见区域和新显露区域分别量化。小样本只用于路线筛查，不足以报告稳定的分布指标或总体成功率。

如果连多帧、小位移、短时的受限任务也没有好画面，应先修数据对齐、几何尺度或条件注入，不加长上下文和世界模型叙事。如果受限任务成功，再选择一个具体失败问题深入：例如观测到的修正是否传播，而不是一次增加记忆、动态分解、因果 codec 和实时蒸馏。

SpatialVID 后续筛选更应看相机/深度可信度、视图重叠、遮挡比例、动态程度、是否切镜和能否回访，不宜只按街景/无人机标签划域。真实闭环不足时需要额外数据；把动态视频倒放不等于真实回访。

该转型保留现有 NPU/DDP、OBS 双写、缓存、吞吐与评估基础设施。R7 的投入可以成为表示对照和重建参照，不应变成项目必须继续使用它的理由。
